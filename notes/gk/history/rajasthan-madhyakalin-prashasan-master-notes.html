⭐ 4. सिरोपाव व सेना संगठन

  • सिरोपाव क्रम (मारवाड़): हाथी(सर्वोच्च) → घोड़ा → पालकी → कड़ा दुशाला(साधारण)
  • माधव रिसाला व राज्य रिसाला — कोटा की घुड़सवार सेना विभाजन
  • गंगा रिसाला — बीकानेर (गंगासिंह, ऊँट सेना, 1889)
  • प्यादे — राजपूत सेना के पैदल सैनिक
  • रुखवाली भाछ — बीकानेर, लूट-खसोट रोकने हेतु नया सैनिक कर
  • बाहर चढ़ना — मारवाड़ में डाकुओं के विरुद्ध फौजदार/ठाकुर का अभियान
  • खास रूक्का — प्रथम श्रेणी सामन्तों को युद्धकाल बुलावा-पत्र

🎯 6. Last-Minute One-Liners (⚡ Rapid Revision)

  • अक्षपटलिक = मुख्य लेखाधिकारी
  • प्रधान = राजा के बाद सर्वोच्च
  • हाथी सिरोपाव = सर्वोच्च सम्मान
  • जागीर = फारसी शब्द
  • जैसलमेर = उत्तराधिकारी शुल्क नहीं
  • डावी-जीवणी = जैसलमेर
  • सोलह-बत्तीस-गोल = मेवाड़ (उमराव)
  • मदद-ए-माश = विद्वानों हेतु करमुक्त भूमि (=सयूरगल)
  • सद्र = मदद-ए-माश अधिकारी
  • वकील = मुगल दरबार प्रतिनिधि
  • बापीदार = खुदकाश्त (स्थायी) किसान
  • लाटा = फसल में हिस्सा बाँटना
  • कूंता = अनुमानित लगान (तोल नहीं)
  • ईजारा = राजस्व ठेका प्रणाली
  • महकमा बकायत = शेष राजस्व वसूली
  • कांसा परोसा = विवाह/मृत्यु भोज कर
  • सिंगोटी = पशु-बिक्री कर
  • खालसा = राज्य की प्रत्यक्ष भूमि
  • पसायत = सेवा-भूमि
  • प्यादे = पैदल सैनिक
  • बीघोड़ी = मारवाड़-बीकानेर, प्रति बीघा लगान
  • मुकाता = नगदी फसल कर
  • साहणे = राज्य-भाग निर्धारण अधिकारी
  • चौधरी/पटेल = ग्राम प्रमुख (पटवारी नहीं)
  • जकात = बीकानेर का सीमा/चुंगी कर
  • सायर = जयपुर-जोधपुर का वही कर
  • माधव रिसाला = कोटा
  • गंगा रिसाला = बीकानेर
  • भरतु रेख = मारवाड़ में रेख का नाम
  • तागीरात = अजीतसिंह द्वारा नया कर
  • सामन्त व्यवस्था आधार = रक्त सम्बन्ध + कुलीय भावना (स्वामी-सेवक नहीं)
  • जेम्स टॉड ने तुलना की = इंग्लैंड की फ्यूडल व्यवस्था से
  • छेली राशि = जयपुर का विधवा-पुनर्विवाह कर
  • तिवारा कर = होली-दिवाली पर
  • भीषगाधिराज = मुख्य वैद्य (PM नहीं)

🚨 7. Answer Key सत्यापन नोट्स
