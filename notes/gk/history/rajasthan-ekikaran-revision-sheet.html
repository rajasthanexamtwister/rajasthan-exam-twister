🔥 KEY FACTS — CM से सम्बंधित
  • JNV (जय नारायण व्यास) = एकमात्र CM जो मनोनित भी + निर्वाचित भी
  • C.S. वेंकटाचार = ICS अधिकारी, गैर-राजनेता CM
  • मोहनलाल सुखाड़िया = सबसे लंबा कार्यकाल (17 वर्ष) = "आधुनिक राजस्थान के निर्माता"
  • टीकाराम पालीवाल = पहले निर्वाचित CM (1952 आम चुनाव)

⚡ रैपिड रिवीज़न — अंतिम 5 मिनट

चरण → उद्घाटनकर्ता

  • 1+2 → गाडगिल
  • 3 → नेहरू (उदयपुर)
  • 4+5 → सरदार पटेल

चरण → PM/CM

  • 1 → शोभाराम कुमावत
  • 2 → गोकुल लाल असावा
  • 3 → माणिक्यलाल वर्मा
  • 4,5,6 → हीरालाल शास्त्री
  • 7 → मोहनलाल सुखाड़िया

चरण → राजधानी

  • 1 → अलवर
  • 2 → कोटा
  • 3 → उदयपुर
  • 4,5,6,7 → जयपुर

विभाग (शहर)

  • जोधपुर → हाईकोर्ट
  • बीकानेर → शिक्षा
  • भरतपुर → कृषि
  • उदयपुर → खनिज
  • कोटा → वन

समिति → काम

  • शंकरराव देव → मत्स्य विलय
  • B.R. पटेल → राजधानी विवाद
  • सत्यनारायण राव → विभाग पुष्टि
  • फज़ल अली → राज्य पुनर्गठन

रियासत → खासियत

  • जोधपुर → सबसे बड़ी (क्षेत्र)
  • जयपुर → सबसे बड़ी (जनसंख्या)
  • शाहपुरा → सबसे छोटी + जनतंत्र
  • जैसलमेर → सबसे पिछड़ी
  • मेवाड़ → सबसे प्राचीन
