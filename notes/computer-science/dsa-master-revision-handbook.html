🚨 मेरी Exam Traps & Confusions (Highest Priority)

Trap 1 — Stack vs Queue: Stack = LIFO/FILO (दोनों नाम सही, समान अर्थ) · Queue = FIFO
🧠 Push=Insert, Pop=Delete (Stack) · Enqueue(Rear)=Insert, Dequeue(Front)=Delete (Queue)
Trap 2 — DFS vs BFS: DFS→Stack (गहराई) · BFS→Queue (Level by level)
🧠 "Deep=Stack, Broad=Queue"
Trap 3 — BST Traversal: केवल Inorder = Sorted Ascending; Preorder/Postorder Sorted नहीं होते
Trap 4 — Compiler vs Interpreter vs Assembler (सबसे ज़्यादा दोहराया गया — 12+ बार):
TranslatorInput→Outputतरीका
CompilerHigh-Level → Machine Codeपूरा Program एक साथ
InterpreterHigh-Level → Direct Execute (बिना पूरा Machine Code बनाए)Line by Line
AssemblerAssembly → Machine Codeएक साथ
🔗 यह IDE के "Build" Feature से जुड़ा है — Build = Source Code को Executable/Deployable Form में बदलना (Compiler इसी में उपयोग होता है)।
Trap 5 — AVL Balance Factor: Valid = –1,0,+1 · ≥2 या ≤–2 → Rotation (LL/RR/LR/RL)
Trap 6 — Full Binary Tree: n leaves → Total Nodes = 2n–1 (2n या n+1 नहीं)
Trap 7 — Spanning Tree Edges = V–1 (V edges नहीं)
Trap 8 — Binary Search: केवल Sorted Array पर चलती है; Unsorted पर पहले Sort करना ज़रूरी
Trap 9 — Max-Heap vs Min-Heap vs BST: Heap केवल Complete Binary Tree की Parent≥/≤Children Property रखता है; BST जैसा Left
Trap 10 — Stack Overflow Index (PYQ BCI 2022): SIZE=11, top=-1 → Max valid top = 10 (Index 0–10)
Trap 11 — i++ का अर्थ: i++ = i = i + 1; (RSMSSB LDC 2018 — 2 बार पूछा गया)
Trap 12 — = vs ==: = Assignment है, == Comparison है। तीन Variable बराबर जाँचना: age1==age2 && age2==age3
Trap 13 — Internal vs External Sorting (Coaching Material में Confusion): मानक Theory में Merge Sort भी Internal हो सकता है (यदि पूरा Data RAM में हो), पर पुराने Objective GK Pattern में इसे प्रायः External Sort माना गया है — प्रश्न के Context अनुसार उत्तर दें। ⚠️ Verify Required (Source-dependent)
Trap 14 — Slowest Sorting Algorithm: Bubble और Selection दोनों Worst=O(n²), पर "Slowest Practical" पूछने पर Exam Answer प्रायः Bubble Sort होता है
Trap 15 — Java 016 Octal Trap: Java में 0 से शुरू Number = Octal माना जाता है → 016(Octal) = 1×8+6 = 14(Decimal)
Trap 16 — String Array Default Value: Java में Object/Reference Array के खाली Elements का Default = null (Primitive का 0 नहीं)
Trap 17 — C++ Class Default Access: Class Members Default = Private · Struct Members Default = Public
Trap 18 — C में class नहीं होता (यह C++ का Data Type है, C Procedural है)
Trap 19 — Logical vs Relational Operators: Logical = && || ! · Relational = > < == — एक Quiz में इन्हें गलत Classify किया गया था (देखें 🚨 Answer Key Doubts)

3️⃣ Data Structures & Algorithms

Linear vs Non-Linear

LinearNon-Linear
Array, Stack, Queue, Linked ListTree, Graph

Stack ⭐⭐⭐ (सबसे पसंदीदा Topic)

  • LIFO/FILO · Push=Add · Pop=Remove
  • Uses: Recursion, Infix→Postfix/Prefix Conversion, Undo, Parenthesis Matching, DFS 🔗(Prog. भाषा में Recursion भी इसी से Implement होती है)
  • Overflow: top=SIZE-1 · Underflow: top=-1
Infix→Postfix Rule: Precedence ^ > */ > +− । Operand→direct output; (→push; )→pop till(; Operator→pop higher/equal precedence फिर push; अंत में सब pop करो।
ExpressionPostfix
A+B*CABC*+
a+b*c+(d*e)abc*+de*+

Queue

TypeFact
Simple QueueFIFO · Front से Delete, Rear से Insert · Overflow: REAR==N-1
Circular QueueOverflow: (REAR+1)%N==FRONT · Empty: FRONT==REAR==-1
Dequeदोनों ends पर Insert/Delete
Queue के प्रकार: Ordinary, Circular, Priority — Single-ended कोई Type नहीं है (⭐PYQ Trap)। Queue बनाने के लिए Minimum 2 Stack चाहिए और Stack बनाने के लिए 2 Queue।

Tree ⭐⭐⭐ (सबसे ज़्यादा PYQ)

TraversalOrderKey Fact
InorderLeft→Node→RightBST में Sorted Ascending
PreorderNode→Left→RightNode पहले
PostorderLeft→Right→NodeNode अंत में
Level OrderLevel by level= BFS, Queue-based, DFS नहीं
BST: Left<Parent<Right · Best/Avg=O(log n), Worst(skewed)=O(n) · n keys से Possible BST संख्या = Catalan Number C(2n,n)/(n+1)
AVL: Balance Factor=Height(L)−Height(R) · Valid=−1,0,+1 · Rotations: LL/RR/LR/RL
Heap: Max-Heap Root=Max, Parent≥Children · Min-Heap Root=Min, Parent≤Children · Priority Queue के लिए Heap Best

Graph

  • Tree = Connected Graph बिना Cycle · Spanning Tree Edges=V−1
  • DFS→Stack · BFS→Queue(Shortest path in unweighted)
  • MST: Kruskal's + Prim's (Greedy) · Shortest Path: Dijkstra's(single source) · All-pairs: Floyd-Warshall(DP)
  • Undirected max edges = n(n−1)/2 · Sum of degrees = 2×edges · Odd-degree vertices हमेशा Even संख्या में होते हैं

Searching

AlgoConditionComplexity

Array Address Formula

Row-major: Base+[(i−LB_row)×cols+(j−LB_col)]×size · Column-major: Base+[(j−LB_col)×rows+(i−LB_row)]×size
C/C++/Java→Row-major · Fortran/MATLAB/R→Column-major

Array Traversal (Algorithm PYQ)

Repeat for K=LB to UB: Apply PROCESS to LA[K] = Traversal (हर Element को exactly एक बार Visit करना, O(n)) — Searching नहीं (Target नहीं ढूँढ रहा), Sorting नहीं (कोई Swap नहीं)

Hashing

Search=O(1) average · Collision Resolution: Linear Probing, Chaining(Deletion आसान) · Load Factor=n/m

📌 One-Line Revision

  • Compiler=पूरा Program एक साथ Convert · Interpreter=Line by Line · Assembler=Assembly→Machine
  • Stack=LIFO(Push/Pop) · Queue=FIFO(Enqueue/Dequeue)
  • DFS=Stack · BFS=Queue=Level Order
  • BST Inorder=Sorted · AVL BF=−1,0,+1
  • Full Binary Tree: n leaves→2n−1 nodes · Spanning Tree: V−1 edges
  • Binary Search केवल Sorted Array पर, O(log n)
  • Merge/Heap Sort हमेशा O(n log n); Quick Sort Worst=O(n²)
  • IDE=Editor+Compiler/Interpreter+Debugger+Build; Build=Executable बनाना (Run नहीं)
  • OOP 4 Pillars: Encapsulation, Inheritance, Polymorphism, Abstraction

🧮 Algorithm Complexity Cheat-Sheet

Complexity Order (Ascending): O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)
Big-O=Upper/Worst bound · Omega(Ω)=Lower/Best bound · Theta(Θ)=Tight/Average bound

🧠 Memory Tricks & Mnemonics

  • Stack=LIFO="Last plate first use" · Queue=FIFO="Bus line"
  • DFS="Deep→Stack" · BFS="Broad→Queue"
  • Traversal: In=LNR, Pre=NLR, Post=LRN
  • AVL="Always Valid Levels (−1,0,1); 2 से Rotation आती है"
  • Merge Sort worst=O(n log n)="Merge हमेशा Smart" · Quick Sort worst=O(n²)="Quick कभी-कभी गड़बड़"
  • Row-major="Row wale Real programmers(C/C++/Java)" · Column-major="Column wale Formula wale(Fortran/MATLAB/R)"
  • Bubble="Big goes Back" · Selection="Smallest to Start" · Insertion="Index 1 से तुलना शुरू"
  • IDE="I Do Everything" (एक ही जगह Code, Compile, Debug)
  • Connection-chain Trick: "भाषा लिखो(Prog Lang) → Structure बनाओ(DSA) → IDE में चलाओ"

🚨 Answer Key Doubts / Source Conflicts

1. Logical Operators Question (Prog. Quiz 6): दी गई Answer Key >,<,= को Logical Operator बताती है — यह वास्तव में Relational Operators हैं। Logical Operators होते हैं && || !। ➡️ Answer Key Doubt।
2. C में User Defined Function Keyword (Quiz 5): दी गई Answer "define" संदिग्ध है — C में User Defined Function के लिए कोई Fixed Keyword नहीं होता; यह केवल #define (Macro) से Confuse हुआ लगता है। ➡️ Faulty Question।
3. Dynamic Web Pages Software (Quiz 5): दी गई Answer "Ruby" — प्रश्न "Software" पूछता है जबकि Ruby एक Language है, न कि Software। ➡️ प्रश्न अस्पष्ट/Faulty।
4. OOP Blueprint Question (Quiz 4): Options में सही उत्तर "Class" नहीं दिया गया था (Options: Inheritance/Polymorphism/Encapsulation/Abstraction)। ➡️ Faulty Question।
5. Internal vs External Sorting (Merge Sort): ⚠️ SYLLABUS CHECK NEEDED — मानक Theory अनुसार RAM में Sort होने पर Merge Sort Internal भी हो सकती है, पर पुराने Objective GK Pattern में इसे External माना गया। Context देखकर उत्तर दें।
