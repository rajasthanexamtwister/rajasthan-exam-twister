🚨 परीक्षा में होने वाली गलतियाँ (EXAM TRAPS)

Trap 1: Stack = LIFO (Last In First Out) ✅ | Queue = FIFO (First In First Out) ✅
❌ गलती: FIFO/LIFO को stack/queue में उल्टा लिखना — PYQ में बार-बार आता है!
Trap 2: DFS uses Stack · BFS uses Queue
❌ गलती: DFS में Queue सोचना — याद रखो: DFS = Depth = Stack (नीचे जाता है)
Trap 3: BST का Inorder = Sorted Ascending ✅
❌ गलती: Preorder को sorted समझना — केवल Inorder sorted होता है BST में
Trap 4: AVL Tree का Balance Factor = –1, 0, या +1 ✅
❌ ≥2 या ≤–2 होने पर Unbalanced → Rotation लगाओ
Trap 5: Full Binary Tree में n leaf nodes → total nodes = 2n–1
❌ गलती: 2n या n+1 लिखना
Trap 6: Spanning Tree edges = V–1 (V = vertices)
❌ गलती: V edges लिखना
Trap 7: Push = Stack में add करना · Pop = Stack से remove करना
❌ गलती: Push/Pop को उल्टा सोचना
Trap 8: Binary Search → Array sorted होना जरूरी! Unsorted array पर binary search नहीं होती।
❌ गलती: unsorted array पर binary search apply करना
Trap 9: Max-Heap में root = maximum · Min-Heap में root = minimum
❌ Heap को BST समझना — Heap में left/right का BST जैसा order नहीं होता
Trap 10 (PYQ BCI 2022): Stack SIZE=11, top=-1 → max top = 10 (index 0–10)
❌ गलती: 11 या 9 लिखना

⭐⭐ Infix → Postfix Conversion Rules

Precedence: ^ (highest) > * / > + - (lowest)
1. Operand → direct output
2. ( → push on stack
3. ) → pop until ( found
4. Operator → pop higher/equal precedence then push
5. End → pop all remaining

⭐⭐ QUEUE

Queue
FIFO · Front से delete · Rear से insert · Applications: BFS, scheduling, async transfer
Circular Queue
Ring buffer · Overflow: (REAR+1)%N == FRONT · Empty: FRONT==REAR==-1
Deque
Both ends insert/delete · Double-ended queue · Linear data structure
⚠ Confused: Simple Queue overflow: REAR == N-1 · Circular Queue overflow: (REAR+1)%N == FRONT
Queue types: Ordinary, Circular, Priority (Single-ended = NOT a type ⭐PYQ)
PYQ: Queue implement करने के लिए minimum 2 stacks चाहिए · Stack implement करने के लिए 2 queues

BST (Binary Search Tree)

BST Rules:
• Left child < Parent
• Right child > Parent
• Inorder → Ascending order
• Delete root → successor = inorder successor (immediate right subtree का leftmost) या predecessor
BST Operations Time:
• Best/Avg: O(log n)
• Worst (skewed): O(n)
• Skewed tree: सभी एक तरफ right child
• n nodes से कितने BST? = Catalan number
🧠 Catalan Number: n distinct keys से BST की संख्या = C(2n,n)/(n+1)
n=4 → 14 · n=6 → 132

⭐⭐ GRAPH

Key Facts:
• Vertices + Edges
• Tree = Connected Graph (cycle नहीं)
• Simple Graph: No self-loop, No parallel edge
• Undirected n-vertex max edges = n(n-1)/2
• Complete graph edges = n(n-1)/2
• Isolated vertex degree = 0
• Sum of degrees = 2e (e = edges)
• Odd degree vertices = Always Even number
Traversal:
• BFS → Queue → Level order → Shortest path
• DFS → Stack → Depth first
• DFS types: Inorder, Preorder, Postorder
• Spanning Tree edges = V–1
• MST Algorithms: Kruskal's + Prim's (Greedy)
• Shortest Path: Dijkstra's (single source)
• All pairs: Floyd-Warshall (Dynamic Programming)

⭐ Array Address Formula (PYQ में आता है)

Row-Major (C, C++, Java): Address(A[i][j]) = Base + [(i - LB_row) × columns + (j - LB_col)] × size Column-Major (Fortran, MATLAB, R): Address(A[i][j]) = Base + [(j - LB_col) × rows + (i - LB_row)] × size
PYQ: A[20][10], Base=100, size=4, Row-major → A[11][5] = 100 + [11×10 + 5] × 4 = 100 + 115×4 = 560
⚠ C language → Row-major · Fortran, R, MATLAB → Column-major

🧠 Memory Tricks & Mnemonics

  • LIFO/FIFO: Stack = LILO (Last plate first use) · Queue = FIFO (Bus queue)
  • DFS vs BFS: DFS = Deep = Stack S · BFS = Broad = Queue Q
  • Tree Traversal: In = LNR · Pre = NLR · Post = LRN → "In pre post → Node की position"
  • Complexity order: 1 < log n < n < n log n < n² < 2ⁿ
  • BST Inorder = Sorted: "BST का Inorder = Ascending Result (AIR)" → BIA
  • Heap: MAX = Maximum at top (Mountain peak) · MIN = Minimum at top (Mine = underground = small)
  • Spanning Tree: "n vertices → n–1 edges" → "एक कम किनारे"
  • AVL Balance: "–1, 0, 1 valid · 2 से Rotation आती" → AVL = Always Valid Levels (–1,0,1)
  • Merge Sort worst = O(n log n): "Merge हमेशा Smart" · Quick Sort worst = O(n²): "Quick कभी-कभी गड़बड़"
  • Row-major countries: C/C++/Java → Row wale Real programmers · Fortran/MATLAB/R → Column wale Formula wale

⭐ Hashing

Key Facts:
• Search: O(1) average
• Hash function: same hash for different keys possible (Collision) ⭐
• Load Factor = n/m (n=elements, m=slots)
• Collision resolve: Linear Probing, Chaining
• Chaining: Deletion आसान ✅
PYQ Example:
H(K) = K mod 10
Insert: 40,27,19,48,7 (in order)
40→0, 27→7, 19→9, 48→8, 7→? (7 already taken) → Linear probe → 8 taken → slot 1

⚡ Last-Minute Quick Revision

  • Array = Random access O(1) · Best for matrix representation
  • Stack = LIFO · Push/Pop · Recursion · DFS · Infix conversion
  • Queue = FIFO · Enqueue rear, Dequeue front · BFS · Scheduling
  • Linked List = Dynamic · O(1) insert at beginning · O(n) search
  • Binary Search = Sorted array जरूरी · O(log n)
  • BST Inorder = Sorted · Delete root → inorder successor/predecessor
  • AVL = Height balanced · BF = –1,0,+1 · ≥2 → rotation
  • Heap = Priority Queue · Max/Min root · Complete binary tree
  • DFS = Stack · BFS = Queue · Spanning Tree = V–1 edges
  • Kruskal/Prim = MST = Greedy · Dijkstra = Shortest path · Floyd-Warshall = All pairs DP
  • Merge Sort = Always O(n log n) · Quick Sort worst = O(n²) · Selection Sort always O(n²)
  • Full BT: n leaves → 2n–1 total nodes · Degree of node = subtree count
  • Circular Linked List: NULL नहीं होता · Deque = both ends insert/delete
  • Non-homogeneous data = Array store नहीं कर सकती · Records कर सकती हैं
  • Level Order traversal = NOT DFS based = BFS = Queue
