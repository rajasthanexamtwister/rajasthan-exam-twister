⭐ High-Yield तथ्य — PowerPoint (⭐⭐⭐⭐⭐ सर्वाधिक दोहराए गए)

  • Slide Master — Background, Logo, Font, Placeholder, Bullet, Layout सब Control करता है; एक बार डाला गया Element हर Slide पर एक ही स्थान पर अपने आप आता है।
  • Default Orientation — PowerPoint = Landscape (Portrait भी सेट किया जा सकता है, PPT हमेशा Landscape तक सीमित नहीं)।
  • Views — Normal (Edit), Outline (केवल Text), Slide Sorter (सभी Slides Thumbnail, Rearrange), Notes Page (Speaker Notes), Reading, Slide Show (Full Screen)। Print Layout PPT में नहीं है (वह Word का है)।
  • Template — Predefined Presentation (Font+Layout+Background सब सहित); Theme सिर्फ Color+Font तक सीमित है।
  • Placeholder — Slide पर Text/Picture/Chart रखने का Container।
  • Animation Categories — Entrance, Emphasis, Exit, Motion Path। Spin=Rotate; Motion Path=Object को रास्ते पर घुमाना।
  • Transition Categories — Subtle, Exciting, Dynamic Content।
  • Handout — Audience के लिए Printed Copy; Slides/Page विकल्प = 1,2,3,4,6,9।
  • Auto Content Wizard (पुराना PPT) — Start → Presentation Type → Presentation Style → Presentation Options → Finish (Start-Finish के बीच 3 Steps)। Title/Footer Step-3 में तय होते हैं। Style Step में: On-Screen, Web, Black&White Overheads।
  • Zoom Range — 10% से 400% (Status Bar Slider)।
  • Font Size — Toolbar Dropdown: 8–96; असल Typed Range: 1–4000।
  • Character Spacing — 0pt से 1000pt।
  • Default File Name — Presentation1; Default Extension (2007+) = .pptx; Macro Enabled = .pptm; Slide Show Direct-Open = .ppsx; Template = .potx.
  • Insert Tab — Picture, ClipArt, Shapes, Audio, Video, Header&Footer/Slide Number (Text Group), Hyperlink, WordArt, SmartArt।
  • Home Tab — Slide Layout, Clipboard (Cut/Copy/Paste/Format Painter — New Slide यहाँ नहीं है, वह Slides Group में है), Editing Group (Find/Replace/Select), Reset।
  • Design Tab — Background बदलना, Color Scheme, Themes।
  • Slide Show Tab — From Beginning, From Current Slide, Present Online, Rehearse Timings, Custom Slide Show, Set Up Slide Show (Loop Continuously Until Esc)।
  • Quick Access Toolbar — Title Bar पर Save/Undo/Redo (Ribbon से अलग)।
  • PowerPoint एक Application Software है, GUI आधारित।

🚨 Answer Key Bugs / विवादित प्रश्न

PPT — "Program to create Presentation": Book Answer=Access (❌ गलत) → सही उत्तर=PowerPoint (Access एक Database Program है)
PPT — "Change color of entire presentation किस Tab से": दिए गए Options (File/Home/View/Review) में से कोई सही नहीं — असल उत्तर Design Tab है जो Options में था ही नहीं (Flawed Question)
PPT — Character Spacing Range: एक जगह Book Answer=100–1000pt, दूसरी जगह 0–1000pt — Standard सही उत्तर 0–1000pt मानें
PPT — "कौनसा Format Add नहीं कर सकते": Book Answer=.gif (❌ गलत, GIF Supported है) → सही उत्तर=.html (Web Format, Direct Insert नहीं होता)
DBMS — "Data Item Storage": Book Answer=Database (❌) → सही उत्तर=Field (Data Hierarchy अनुसार)
DBMS — "Data Integrity Problem का कारण": Book Answer=Lack of Availability (❌) → सही उत्तर=Data Duplication/Redundancy
DBMS — "Relational Model में क्या होता है": Book Answer=Entity (❌) → सही उत्तर=Table (Entity, ER Model का Concept है, Relational Model का नहीं)
DBMS — "MS Access किस प्रकार का Database": Book Answer=All of the above (❌) → सही उत्तर=केवल Relational Database
DBMS — "ER Model किसने दिया": Book Answer=Dr. E.F. Codd (❌, विकल्पों में सही जनक Peter Chen नहीं दिया गया — Question ही Flawed है)। याद रखें: Codd=Relational Model, Chen=ER Model

📚 Topic-wise Revision — MS Access / DBMS High-Yield

  • DBMS Advantage — Data Independence, Security, Integrity, Reduced Redundancy, Sharing। Disadvantage: Cost, Complexity।
  • DDL — Structure (CREATE, ALTER, DROP, TRUNCATE) | DML — Data (SELECT, INSERT, UPDATE, DELETE)
  • Keys — Primary Key=Unique पहचान; Foreign Key=दो Tables को जोड़ता है; Composite Key=एक से अधिक Field; Weak Entity=अपनी Primary Key नहीं रखता
  • ER Diagram — Rectangle=Entity, Ellipse=Attribute, Diamond=Relationship
  • Data Models — Hierarchical=Tree; Network=Graph; Relational=Table
  • Three-Level Architecture — External → Conceptual (Logical) → Internal (Physical)
  • Access Objects — Table (Store), Query (View/Filter/Analyse — Dynaset लौटाता है), Form (Data Entry), Report (Print), Macro (Automation)
  • Access Views — Design View (Structure) और Datasheet View (Data) — दोनों से Table बन सकती है
  • Access Tabs — Home, Create, External Data (Import/Export), Database Tools (Relationships/Compact-Repair)
  • Access Facts — Default Extension=.accdb (पुराना .mdb); Default Data Type=Text; Table/Field Name Max Length=64 Characters; Title Bar=Database नाम दिखाता है
  • Alt+F4=Access बंद करना; Ctrl+W=केवल Object बंद करना

📚 Topic-wise Revision — MS Word (Quick Recap)

  • Alignment: Ctrl+L/E/R/J; Justify की Last Line Left रहती है
  • Mail Merge=एक Letter, अलग-अलग Recipients; Data Source में PowerPoint मान्य नहीं
  • F7=Spelling/Grammar; Ctrl+F2=Print Preview; F12=Save As; Ctrl+D=Font Dialog
  • Gutter Margin=Binding Side की अतिरिक्त जगह; Indentation=Paragraph शुरुआत की जगह
  • Drop Cap=पहला अक्षर बड़ा (Insert Tab)
  • Default File Name=Document1; Default Extension=.docx; Default Font (2007+)=Calibri
  • Styles=पूरे Document में एक जैसी Formatting; Macro=Automation (Language: VBA)

📚 Topic-wise Revision — MS Excel (Quick Recap)

  • Cell Reference: Relative(A1)=बदलता है; Absolute($A$1)=Lock; Mixed($A1/A$1)=आधा Lock
  • Rows=1,048,576 | Columns=16,384 (2007+); पुराना (2003)=65,536 Rows
  • Formula हमेशा = से शुरू होता है
  • COUNT=केवल Numbers; COUNTA=Non-empty; COUNTIF=Condition आधारित; SUM=जोड़
  • TODAY()=Date; NOW()=Date+Time (दोनों अलग हैं)
  • Pivot Table=Summary/Analysis का Tool; Conditional Formatting=Condition पर Highlight
  • Freeze Panes=Scroll करने पर Row/Column Fix रखना
  • Goal Seek=एक Variable Optimize करना; Solver=Multiple Variable + Constraints के साथ Advanced Optimization
  • Default Font (2019)=Calibri 11; Default Extension=.xlsx (पुराना .xls)
