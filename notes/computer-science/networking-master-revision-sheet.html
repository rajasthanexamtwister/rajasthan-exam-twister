⭐ HIGH-YIELD EXAM FACTS

  • OSI Model = 7 Layers; TCP/IP Model = 4 Layers (DOD Model)
  • TCP/IP क्रम (नीचे से ऊपर): Network Access → Internet → Transport → Application
  • OSI Mnemonic 🧠: Please Do Not Throw Sausage Pizza Away (Physical-DataLink-Network-Transport-Session-Presentation-Application)
  • IPv4 = 32 Bit (Dot separated); IPv6 = 128 Bit (Colon separated)
  • PDU क्रम: Bits→Frame→Packet→Segment (Physical→DataLink→Network→Transport)
  • Router = Network Layer (L3); Switch = Data Link (L2); Hub = Physical (L1)
  • FTP = 2 TCP Connections: Port 21 (Control), Port 20 (Data - Active FTP)
  • SMTP = Send Mail (Port 25); POP3 = Receive/Download; IMAP = Receive+Sync
  • HTTP = Port 80 (Plaintext); HTTPS = Port 443 (SSL/TLS Encrypted)
  • DNS = Domain Name System (Domain → IP Address)
  • ARP = IP→MAC; RARP (अप्रचलित) = MAC→IP
  • DHCP = UDP आधारित, Port 67 (Server)/68 (Client), Auto IP Configuration
  • ARPANET = विश्व का पहला Computer Network / Internet का आधार (1969, DARPA)
  • WWW आविष्कारक = Tim Berners-Lee (1989); पहली Website = CERN
  • प्रथम भारतीय Public ISP = VSNL (1995)
  • MAC Address = 48 Bit (6 Bytes / 12 Hex Digits)
  • Mesh Topology Cable Formula = n(n−1)/2
  • Bluetooth = PAN (Personal Area Network) तकनीक
  • Ethernet Card = NIC (Network Interface Card)
  • Traditional Ethernet Speed = 10 Mbps
  • Base64 Encoding: 24 Bit → चार 6-Bit Blocks → 32 Bit output
  • Stateful Packet = TCP; Stateless = UDP
  • Class B Default Subnet Mask = 255.255.0.0; Class C = 255.255.255.0
  • IPv4 Class D (224–239) = Multicasting हेतु
  • RJ45/UTP Cable = 4 Twisted Pairs (8 Wires)
  • Optical Fiber = सर्वाधिक Bandwidth/Speed; Coaxial की बाहरी Shielding Noise कम करती है
  • Modem = Modulator + Demodulator (Digital↔Analog Converter)
  • DDoS = Distributed Denial of Service (Multiple Attackers); DoS = Single Attacker
  • IPSec = Internet Protocol Security (VPN में प्रयुक्त)
  • Spoofing = Fake Identity; Phishing = Password/Data चोरी; Spamming = Bulk Junk Mail
  • Rootkit = Hidden Admin Control; Trojan = Legitimate दिखने वाला Malware; Worm = Self-Replicating (बिना Host)
  • NGFW (Next Generation Firewall) = Traditional/Stateful से अधिक Secure (DPI, IPS, App Control शामिल)
  • Honeypot = Attackers को आकर्षित करने वाला Decoy System
  • Ethical Hacking Phases 🧠 "R S G M C": Reconnaissance→Scanning→Gaining Access→Maintaining Access→Covering Tracks

⚠ Frequently Confused Facts

  • Internet ≠ WWW (WWW एक Service है जो Internet पर चलती है)
  • Modem ≠ Router (Modem Signal Convert करता है, Router Route करता है)
  • NIC = Ethernet Card = Network Interface Card (तीनों एक ही)
  • Cookies ≠ Plugins/Extensions (अलग-अलग कार्य)
  • Eavesdropping (Real-time Secret Listening) ≠ Snooping (Unauthorized Data Browsing)
  • DDoS ≠ DOS Operating System (केवल Attack का नाम है)
  • Bandwidth ≠ Data Transfer Rate (Capacity vs Actual Speed)
  • Static IP ≠ Unique IP (अलग Concept)

📚 Sub-topic-wise Revision

1️⃣ Network & Communication

  • मूल Communication System (Shannon-Weaver Model) 🧠: Information Source → Sender → Channel → Receiver → Destination
  • Simplex (एकदिशीय) / Half Duplex (दोनों दिशा, एक समय में एक — जैसे Walkie-Talkie) / Full Duplex (दोनों दिशा एक साथ — जैसे Mobile Phone)
  • Topologies: Bus (Single Backbone, कम Reliable), Star (Central Hub — सबसे Common), Ring, Mesh (n(n−1)/2 Cables), Tree
  • Transmission Media: Twisted Pair < Coaxial < Optical Fiber (Bandwidth बढ़ते क्रम में)
  • Network Types: PAN(Bluetooth) → LAN(Office) → MAN(City) → WAN(Internet)
  • Terminal = Multi-user System में Central Computer से जुड़ने हेतु Device
  • 🔗 आगे यह Communication ही TCP/IP Layers से होकर गुज़रता है (नीचे देखें)

2️⃣ TCP/IP Model

  • 4 Layers: Application → Transport → Internet → Network Access
  • Application Layer Protocols: HTTP, FTP, SMTP, DHCP, RDP, DNS
  • Transport Layer: TCP, UDP
  • Internet Layer: IP, ICMP, IGMP, ARP
  • Network Access Layer: Ethernet, FDDI
  • Router Network Layer पर, Firewall Network/Application दोनों Layer पर (प्रकार अनुसार) कार्य करता है
  • 🔗 यही Model Internet Services (नीचे) को Layer-by-Layer संभव बनाता है

3️⃣ अंतरजाल (Internet)

  • WWW = Internet पर चलने वाली एक Service (Internet ≠ WWW)
  • Browser: Web Pages Access/Display करने वाला Software (Chrome, Firefox, Edge)
  • Search Engine: जानकारी खोजने हेतु (Google, Bing) — Spider/Crawler Program से कार्य करता है
  • URL = Uniform Resource Locator (Web Address); URI = Resource Identifier (Superset)
  • Email Structure: username@domain.com (Header, Body/Message, Signature — Footer अनिवार्य नहीं)
  • CC = Visible Copy; BCC = Blind (Hidden) Carbon Copy
  • Cloud Storage उदाहरण: Google Drive, OneDrive, Dropbox (इंटरनेट कनेक्टिविटी आवश्यक)
  • Gmail Attachment Limit = 25 MB (इससे बड़ा → Google Drive Link में बदल जाता है)
  • ISP = Internet Service Provider (Jio, Airtel, BSNL) — User को Access देता है
  • 🔗 HTTPS (Secure Web) → विस्तार देखें Network Security → Encryption सेक्शन

4️⃣ Network Security 🔗

  • Firewall = Trusted Private Network को Untrusted External Network से बचाता है
  • Malware Types: Virus (Host चाहिए), Worm (Self-Replicate), Trojan (Legitimate जैसा दिखे), Rootkit (Admin Control), Spyware, Ransomware
  • Attacks: Spoofing (Fake Identity), Phishing (Data चोरी), Spamming (Bulk Mail), Sniffing (Traffic Capture), Eavesdropping (Real-time Listening), DoS/DDoS (Service रोकना)
  • Backup Types: Full (पूरा Data), Incremental (Last Backup के बाद Change), Differential (Last Full Backup के बाद Change)
  • Hacker Types: White Hat (Ethical), Black Hat (Cracker/Criminal), Grey Hat (मध्य)
