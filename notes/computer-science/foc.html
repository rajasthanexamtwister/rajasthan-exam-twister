🧠 Memory — पूरा Reference (Hierarchy + Units + Types)

Memory Hierarchy (Speed: Fast → Slow)

Register → Cache(L1→L2→L3) → RAM → SSD → HDD → Optical Disk → Magnetic Tape (सबसे धीमा)
🧠 Speed ↑ = Size ↓ = Cost ↑ (ऊपर जाओ — तेज़, छोटा, महँगा)
Speed ↓ = Size ↑ = Cost ↓ (नीचे जाओ — धीमा, बड़ा, सस्ता)
RC-RSS-M: Register → Cache → RAM → SSD → HDD → Magnetic Tape
💡 Locality of Reference: Cache इसी principle पर काम करती है
Temporal = हाल में use हुआ data फिर use होगा
Spatial = पास वाले address का data भी soon use होगा

Memory Types — Complete Table

Memory Type Volatile? Technology Key Facts
Register Primary ✅ हाँ Flip-Flops सबसे तेज़, CPU के अंदर। Accumulator, Program Counter।
Cache (L1/L2/L3) Primary ✅ हाँ SRAM CPU+RAM के बीच buffer। Locality of Reference।
RAM Primary ✅ हाँ DRAM (Capacitor) Working memory। CPU directly access। Power off → data gone।
ROM Primary ❌ नहीं Semiconductor BIOS store करता है। Read Only। Non-Volatile। Exception: Primary but Non-Volatile!
HDD Secondary ❌ नहीं Magnetic (Iron Oxide) Aluminium platter। Speed = RPM। Moving parts।
SSD Secondary ❌ नहीं Flash Memory HDD से तेज़। कोई moving part नहीं। Shock-resistant।
CD-R Secondary ❌ नहीं Optical WORM = Write Once Read Many। ~700MB।
CD-RW Secondary ❌ नहीं Optical Rewritable। बार-बार लिख सकते हैं।
DVD Secondary ❌ नहीं Optical 4.7 GB (single layer)। 8.5 GB (dual layer)।
Blu-ray Secondary ❌ नहीं Optical 25 GB (single)। 50 GB (dual layer)।
Magnetic Tape Secondary ❌ नहीं Magnetic Sequential access। सबसे धीमा। केवल Backup के लिए।
🚨 ROM का Exception: ROM = Primary Memory है लेकिन Non-Volatile है। "All Primary = Volatile" — यह WRONG है।
🚨 CD vs DVD: CD ≈ 700 MB (MB में) | DVD = 4.7 GB (GB में) — units गलत मत करना।

DRAM vs SRAM ⭐⭐ (सबसे ज़्यादा पूछा जाता है)

Feature DRAM (Dynamic RAM) SRAM (Static RAM)
Component Transistor + Capacitor Flip-Flops (6 transistors)
Refresh ✅ ज़रूरी (capacitor charge leak होता है) ❌ ज़रूरी नहीं
Speed धीमा तेज़
Cost सस्ता महँगा
Density High (ज़्यादा data in less space) Low (ज़्यादा space लेता है)
Power (चालू रहने पर) कम ज़्यादा
Use Main RAM (Primary Memory) Cache Memory
🧠 C-D-R Rule: Capacitor = DRAM = Refresh (कैपेसिटर leak होता है → रोज़ Refresh)
S-F-C Rule: SRAM = Flip-Flop = Cache
DRAM = Daily Refresh (DRAM को daily नहाना पड़ता है)
⚠️ SRAM 'Static' है → यह Non-Volatile नहीं है — बिजली गई तो data जाएगा! दोनों Volatile हैं।
⚠️ SRAM महँगा लेकिन Density कम। DRAM सस्ता लेकिन Density ज़्यादा।

Memory Units — Formula Sheet ⭐⭐⭐

Bit → Nibble(4b) → Byte(8b) → KB(1024B) → MB(1024KB) → GB(1024MB) → TB(1024GB) → PB → EB → ZB → YB
Unit बराबर Powers of 2 Exam Trick
1 Nibble 4 Bits 2² आधा Byte = Half Byte
1 Byte 8 Bits 2³ 1 Character = 1 Byte
1 KB 1024 Bytes 2¹⁰ छोटी text file
1 MB 1024 KB 2²⁰ एक गाना ≈ 3–5 MB
1 GB 1024 MB 2³⁰ Movie ≈ 1–2 GB
1 TB 1024 GB 2⁴⁰ Hard disk size
1 PB 1024 TB 2⁵⁰ Big Data centers
1 EB 1024 PB 2⁶⁰ Internet data/day
1 ZB 1024 EB 2⁷⁰ —
1 YB 1024 ZB 2⁸⁰ सबसे बड़ा standard unit
🧠 Higher units trick: T-P-E-Z-Y (टॉपर इजी है भाई) = TB → PB → EB → ZB → YB

💾 Hard Disk — Structure & Cylinders

HDD Structure (Byte → Platter)

Byte → Sector (512B) → Cluster → Track → Cylinder → Platter
Term Definition
Sector HDD की सबसे छोटी unit = 512 Bytes। Smallest addressable unit।
Track Circular path on platter surface।
Cylinder सभी platters पर same track number = 1 Cylinder। Count = Tracks per surface।
Platter Aluminium disk। Iron Oxide coating। Magnetic data store।
RPM Revolutions Per Minute = Speed measure। 5400, 7200 RPM common।
🚨 Cylinder Calculation Trap:
गलत: 10 surfaces × 5 tracks = 50 Cylinders
सही: Cylinders = Tracks per surface = 5
Cylinder = एक column जो सभी surfaces पर same track number join करता है।
Number of Cylinders = Number of Tracks per surface (surface count से multiply नहीं)
💡 HDD vs SSD:
HDD = Moving parts (Platter + Head)। धीमा। Fragile।
SSD = No moving parts। Flash memory। Fast। Shock-resistant।
Both = Non-Volatile (Secondary Memory)
