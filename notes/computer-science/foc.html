TRAP 1 — Volatile Memory: ROM, HDD, SSD = Volatile
✅ RAM = Volatile (बिजली गई → डेटा गया)। ROM/HDD/SSD = Non-Volatile।
TRAP 2 — Memory Units: 1024 Bytes = 1 GB
✅ 1024 Bytes = 1 KB। Chain: Bit→Nibble(4b)→Byte(8b)→KB→MB→GB→TB→PB→EB→ZB→YB→BB→GBB
TRAP 3 — App vs System Software: Word, Excel, Photoshop = System Software
✅ ये Application Software हैं। System = OS, Driver, Compiler।
TRAP 4 — DTP: DTP (PageMaker) = System Software
✅ DTP/Database = Application Software। System = OS, Driver, Utility, Translator।
TRAP 5 — Impact vs Non-Impact: Laser Printer = Impact
✅ Laser = Non-Impact। Impact = Dot Matrix, Daisy Wheel, Drum, Chain।
TRAP 6 — Plotter: Plotter = Input Device
✅ Plotter = Output Device — CAD, Maps, Engineering diagrams।
TRAP 7 — Browser vs Email: Gmail = Web Browser
✅ Gmail = Email Service। Browser = Chrome, Firefox, Safari, Edge, Opera। KompoZer = HTML Editor।
TRAP 8 — Booting क्रम: पहले OS load होता है
✅ क्रम: BIOS → POST → OS Load। BIOS = ROM का हिस्सा।
TRAP 9 — ICT vs IT: IT = ICT का बड़ा version
✅ ICT बड़ा है, IT उसका subset है (ICT = IT + Communication Tech)।
TRAP 10 — OS vs Antivirus: Fedora, Linux = Antivirus
✅ ये Operating Systems हैं। Antivirus = Avast, Norton, Kaspersky, McAfee।
TRAP 11 — Open Source नहीं: Adobe Photoshop = Open Source
✅ Adobe = Proprietary। Open Source = Linux, Firefox, LibreOffice, GIMP, WordPress।
TRAP 12 — GUI: GUI में Graphs use होते हैं
✅ GUI = Icons, Menus, Colors — Graphs नहीं। MS-DOS = CUI (Command Line), GUI नहीं।
TRAP 13 — Cylinders: 10 surface × 5 track = 50 cylinders
✅ Cylinder = प्रति-सरफेस Track की संख्या → 5 Cylinders (गुणा नहीं करना)।
TRAP 14 — सबसे छोटी Unit: Nibble/Byte = सबसे छोटी unit
✅ Bit (0/1) = सबसे छोटी unit। Bit→Nibble(4)→Byte(8)।
TRAP 15 — ROM Volatility (NEW): Primary Memory हमेशा Volatile होती है
✅ ROM Primary होकर भी Non-Volatile है — यह सबसे बड़ा अपवाद (Exception) है।
TRAP 16 — Virtual Memory (NEW): Virtual Memory सबसे तेज़ Memory है
✅ Virtual Memory = Hard Disk का हिस्सा, इसलिए सबसे धीमी (Worst) मेमोरी स्तर है।
TRAP 17 — Scanner/Plotter (NEW): Scanner दोनों Input+Output है
✅ Scanner = शुद्ध Input, Plotter = शुद्ध Output। दोनों I/O नहीं हैं।
TRAP 18 — DVD Capacity (NEW): DVD हमेशा 4.7GB ही होती है
✅ Single Layer=4.7GB, Dual Layer=8.5GB, Double-side Single Layer≈9.4GB — layer/side अनुसार अलग-अलग।
TRAP 19 — SRAM Density (NEW): SRAM महंगी/तेज़ है तो Density भी ज्यादा होगी
✅ SRAM की Density कम है (6 transistor/cell जगह घेरते हैं); DRAM की Density ज्यादा (1 capacitor/cell)।
TRAP 20 — Register vs Cache (NEW): Cache CPU के सबसे अंदर है
✅ Register सबसे अंदर (CPU का भाग); Cache CPU व RAM के बीच बफर है।

🖥️ CPU Organization (NEW — पूरी तरह नया सेक्शन)

Von Neumann Architecture

  • जनक: John Von Neumann (1945) — 'Father of Computer Architecture / Stored Program Concept'
  • Model: SISD (Single Instruction, Single Data)
  • Flow: Input → Main Memory (RAM) → CPU (ALU+CU+MU) → Output
  • Program = Instructions + Data दोनों Memory में ही store होते हैं
  • CPU Cycle: Fetch → Decode → Execute → Store
Component Full Form कार्य
ALU Arithmetic Logic Unit +,−,×,/,% (Arithmetic); <,>,= (Comparison); NOT/AND/OR/XOR (Logic)
CU Control Unit Computer का "Nerve System/Brain" — Fetch/Decode/Coordinate
MU Memory Unit Registers का समूह (PCR, MAR, MBR आदि)

Registers (⭐ बहुत Important)

🧠 Register = CPU की सबसे तेज़ Storage। Volatile। Flip-Flops से बना। सबसे छोटी Memory।
Register Full Form काम
PCR Program Counter Register अगली Instruction का Address hold करता है
MAR Memory Address Register Active Memory का Address (Binary में) hold करता है
MBR/MDR Memory Buffer/Data Register Active Data hold करता है; CPU-Memory के बीच transfer
IR Instruction Register Current instruction hold करता है
AR Accumulator Register ALU का Result hold करता है

Flip-Flop व Circuits

  • Flip-Flop = Sequential Circuit, 1 Bit data hold करता है, Bistable Device
  • 8 Flip-Flops = 1 Byte (8-bit register)
Circuit Type Output निर्भर करता है Example
Combinational केवल Present Input पर Adder
Sequential Past Output + Present Input दोनों Memory, Flip-Flop

Word Length & CPU Cores

  • Word Length = एक instruction में Processor जितने Bits पर काम करे (जैसे 32-bit, 64-bit)
  • Core = ALU + CU + Register का समूह
Core Type Cores Use
Unicore 1 Single task
Dual Core 2 Everyday tasks
Quad Core 4 Gaming/Multitasking
Hexa Core 6 High performance
Octa Core 8 Mobile processors

Hard Disk Drive (HDD) — Parts

  • Father of Hard Disk: Ray Johnson (IBM) | पहली HDD: RAMAC (5MB)
  • Speed Unit: RPM (Revolution Per Minute)
  • Structure क्रम (Hierarchy): Byte → Sector → Cluster → Track → Platter
  • Sector = सबसे छोटी unit, आमतौर पर 512 Bytes/Sector
  • MBR (Master Boot Record) = पहला Sector, Bootable data store
  • Formula: Storage = Data/Sector × No. of Sector × Recording Surface × Track

🧮 Cache Mapping व Memory Chip — Numericals (NEW सेक्शन)

Cache Memory — Direct Mapping Numerical ⭐⭐⭐⭐⭐

CPU का दिया Address तीन हिस्सों में टूटता है: | Tag | Index | Offset |
Field काम Formula
Offset Block के अंदर कौन-सा Byte चाहिए log₂(Block Size)
Index Cache की कौन-सी Line देखनी है log₂(Cache Size ÷ Block Size)
Tag पहचान — उस Line में RAM का कौन-सा Block रखा है Total Address Bits − Index − Offset
📝 उदाहरण: 32-bit Address, 32 KB Direct Mapped Cache, Block Size = 32 Bytes
Offset = log₂(32) = 5 | Cache Lines = 32KB÷32B = 1024 = 2¹⁰ → Index = 10 | Tag = 32−10−5 = 17
✅ Answer: Index = 10, Tag = 17
🧠 Tag=Identity(कौन-सा Block), Index=Location(कौन-सी Line), Offset=Byte(Block के अंदर)। Block Size दुगुना→Offset+1; Cache Size दुगुना→Index+1; Address Size बढ़े→Tag बढ़ेगा।
🧠 T-I-O Trick: "चाचा(Tag)-घर(Index)-कमरा(Offset)"
⚠️ KB/MB Conversion Trap: Cache Size प्रायः KB/MB में, Block Size Bytes में दिया जाता है — पहले सबको Bytes में बदलें (32KB=32×1024 Bytes)। ⚠️ Associative Mapping में Index नहीं होता (केवल Tag+Offset); Fully Associative में Tag सबसे ज़्यादा होता है।

Memory Chip — Address Lines Numerical ⭐⭐⭐⭐⭐

  • Memory Chip में 3 प्रकार की Lines: Address Lines (Location चुनना), Data Lines (Data भेजना), Control Lines (CS, RD, WR)
Question में क्या दिया है Formula
Memory Organization (जैसे 4M×8, 1M×16) Address Lines = log₂(Total Words)
Total External Connections (Pins) Address Lines = Total Connections − Data Lines − Control/Power Lines
📝 Type-1: 4M-bit Chip, Data Lines=8 → कुल Bits=4×2²⁰=2²² → Words=2²²÷2³=2¹⁹ → Address Lines=19
📝 Type-2: External Connections=19, Data Lines=8, Control/Power=2 → Address Lines=19−8−2=9
🧠 "Organization/Words" दिखे → 2ⁿ Rule; "External Connections/Pins" दिखे → Total−Data−Control
❌ ट्रैप: दोनों Question Types में अलग Formula चाहिए — Language ध्यान से पढ़ो वरना जवाब उल्टा आएगा।

🔢 Number System, Complements & Binary Arithmetic (NEW सेक्शन — BCI का सबसे favourite topic ⭐⭐⭐⭐⭐)

Decimal → Binary → Hex

उदाहरण: Decimal 15 → Binary 1111 → Hex F
Decimal Hex Decimal Hex
10 A 13 D
11 B 14 E
12 C 15 F

Decimal Fraction → Binary (उदाहरण: 26.85)

  • Integer भाग: बार-बार ÷2 करें, Remainder नीचे से ऊपर पढ़ें → 26 → 11010
  • Fraction भाग: बार-बार ×2 करें, हर बार Integer digit लें → 0.85 → 110110 (लगभग)
  • Final: 26.85₁₀ ≈ 11010.110110₂
🧠 Integer भाग → ÷2 (Remainder नीचे से ऊपर)। Fraction भाग → ×2 (Carry digit ऊपर से नीचे) जब तक ज़रूरी bits न मिलें।

1's Complement व 2's Complement

  • 1's Complement: हर 0 को 1, हर 1 को 0 (सीधा Bit Flip, कोई Borrow/Carry नहीं)
Original 0000111100101101
1's Complement 1111000011010010
🧠 1's Complement = सीधा Bit Flip (0↔1); 2's Complement = 1's Complement + 1 (अगला Step, अक्सर साथ पूछा जाता है)

SSD vs HDD — Assertion-Reason रूप ⭐⭐⭐

SSD HDD
Flash Memory, Faster, No Moving Parts Mechanical Disk, Slower, Moving Parts
Assertion: SSD is faster than HDD — ✅ True। Reason: SSD uses Flash Memory — ✅ True, और यह Assertion की सही Explanation भी है (No Moving/Mechanical Parts से Access तेज़)।
🧠 SSD = Flash+Fast+No Moving Parts; HDD = Mechanical+Slow

VPN — क्या करता है, क्या नहीं ⭐⭐⭐

  • VPN Data को Encrypt करता है और असली IP छुपाता है
  • ⚠️ बड़ा ट्रैप: VPN Complete Anonymous नहीं बनाता — VPN Provider खुद User की Activity देख सकता है (Trust VPN Provider पर निर्भर)
🧠 VPN = Encrypt + Hide IP; Complete Anonymous नहीं (Provider देख सकता है) — "टनल तो है, पर अंदर कैमरा (Provider) लगा है"
