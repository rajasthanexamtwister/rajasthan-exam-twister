🧠 Memory Tricks / Mnemonics

  • Memory Speed: R-C-R-S-H = Register→Cache→RAM→SSD→HDD
  • MAR/MDR: Address-Alphabetically-first-MAR; MDR=Data
  • SRAM=Speed=Cache; DRAM=Dynamic=Main Memory
  • Boot Sequence: Power On → POST → BIOS → OS Load
  • Instruction Cycle: Fetch→Decode→Execute (FDE)
  • Generations: Vacuum Tube(1st)→Transistor(2nd)→IC(3rd)→VLSI(4th)→ULSI(5th)
  • WIMP = Windows, Icons, Menus, Pointer (Mouse नहीं)
  • Duplex: Simplex(1-way)→Half-Duplex(दोनों पर बारी-बारी, जैसे Walkie-Talkie)→Full-Duplex(दोनों एक साथ, जैसे Telephone)

📚 Sub-topic-wise Compact Revision (Logical Order)

1️⃣ कम्प्यूटर परिचय

  • Computer = Data Input→Store→Process→Output करने वाला Electronic यंत्र; शब्द "Compute" से बना
  • Father of Computer = Charles Babbage (Analytical Engine, 1837); First Programmer = Ada Lovelace
  • पहला Electronic Computer = ENIAC (1945, Eckert & Mauchly); पहला Stored-Program Binary Computer = EDVAC (Von Neumann concept); पहला Commercial Computer = UNIVAC
  • Generations: 1st=Vacuum Tube(ENIAC,UNIVAC) · 2nd=Transistor(IBM 7030) · 3rd=IC(IBM 360) · 4th=Microprocessor/VLSI(IBM-PC,Apple-II) · 5th=ULSI/AI(Desktop,Laptop)
  • India: पहला Computer=ISI Kolkata · पहला Supercomputer=PARAM 8000(1991,C-DAC Pune) · C-DAC स्थापना=1988 · पहला Bilingual Computer=Siddharth(1986) · Indian Microprocessor=SHAKTI(IIT Madras) · Silicon Valley of India=Bengaluru
  • Classification (Size/Power): Supercomputer(FLOPS में मापी जाती है, Seymour Cray=Father of Supercomputer) > Mainframe > Mini > Micro
  • Working Type: Analog(भौतिक राशि) · Digital(Binary 0/1) · Hybrid(दोनों — जैसे ECG, Radar)

2️⃣ Computer Architecture

  • Architecture concept = John Von Neumann (1970s)
  • CPU = ALU + Control Unit + Registers → "Electronic Brain"; IC चिप = Microprocessor
  • ALU: Arithmetic(+,-,×,÷) + Logical(AND,OR,NOT) + Comparison ops; अधिकतम 1 Output देता है
  • Control Unit: Data Process नहीं करती, केवल Instructions Interpret व Coordinate करती है — → see Memory: MAR/MDR
  • Registers: सबसे तेज़ Memory; PC(Program Counter)=अगले Instruction का Address; MAR/MDR — देखें Memory अनुभाग
  • Buses: Address Bus(Unidirectional) · Data Bus(Bidirectional) · Control Bus(Unidirectional, clock pulses भी ले जाता है)
  • Motherboard घटक: CPU socket, RAM slots, CMOS Battery(BIOS को शक्ति देती है), BIOS Chip, Expansion Slots, SMPS(Switched Mode Power Supply)
  • Instruction/Machine Cycle: Fetch→Decode→Execute(→Store); Instruction Cycle > Machine Cycle > Clock Cycle
  • Booting: Power On→POST(hardware check)→BIOS(ROM firmware)→OS Load; Bootstrap Loader ROM में रहता है
  • Word Size = एक बार में Processor कितने bits Process कर सकता है (आजकल 32/64-bit)
  • Multiprocessing(एक साथ कई Program, कई Processor) vs Multiprogramming vs Time-sharing
  • पहला Microprocessor = Intel 4004(1971, 2300 Transistors, M.E. Hoff & Federico Faggin)
  • DMA(Direct Memory Access) = बड़ा Data तेज़ी से Transfer, CPU को Bypass करके

3️⃣ Computer Memory

  • Primary Memory: RAM(DRAM/SRAM, Volatile) + ROM(PROM/EPROM/EEPROM, Non-volatile) + Cache
  • Cache: CPU↔RAM के बीच, SRAM आधारित, CPU पहले Cache ही Check करता है; L1>L2>L3
  • Secondary Memory: Magnetic(HDD,Floppy,Tape) · Optical(CD,DVD,Blu-ray) · Solid State(SSD, Pen Drive, Memory Card)
  • MAR=Address रखता है, MDR=Data/Instruction रखता है (CPU↔Memory के बीच)
  • Memory Units: 1 Byte=8 Bit, 1 Nibble=4 Bit, 1024 Bytes=1KB, 1024KB=1MB, 1024MB=1GB, 1024GB=1TB, 1024TB=1PB, 1024PB=1EB, 1024EB=1ZB, 1024ZB=1YB
  • Virtual Memory = Secondary Memory का हिस्सा जो RAM की तरह उपयोग होता है (जब RAM कम पड़े)
  • Paging(Non-contiguous storage) vs Swapping(RAM↔Disk) vs Spooling(Printer Queue, SPOOL=Simultaneous Peripheral Operation On-Line)
  • FAT32 = 4GB तक Single File Limit (NTFS/exFAT बड़ी Files के लिए)
  • Firmware = ROM में Stored Software जो Hardware चलाता है

4️⃣ Input/Output Devices

  • Input यूनिट: User Data/Instructions को Binary में बदलती है — Keyboard(101-104 keys, Function Keys F1-F12), Mouse(1963, Douglas Engelbart), Scanner, Joystick, Digitizer, Light Pen, Touch Screen, Trackball, MICR, OMR, OCR, Barcode Reader
  • Output यूनिट: Monitor(CRT/LCD/TFT), Printer(Impact: Dot Matrix,Daisy Wheel,Line,Drum — रिबन उपयोग; Non-Impact: Inkjet,Laser,Thermal — रिबन नहीं), Plotter(Flatbed/Drum), Projector, Speaker
  • Ports: PS/2(Keyboard+Mouse) · VGA(Monitor) · Parallel(Printer, DB25) · Serial/COM(Modem, RS-232, DB9) · USB(Universal, Plug&Play, 1995 Ajay Bhatt) · Ethernet(LAN) · Firewire(400MB/s, Video devices)
  • Display Resolution: 1080p=1920×1080(Full HD); Aspect Ratio=Width:Height(16:9,4:3)
  • Graphics: Vector(Mathematical, Zoom पर Quality नहीं घटती) vs Raster(Pixel आधारित)
  • 3D Printer पहला = Chuck Hull(1984); सबसे उन्नत Printing तकनीक = 3D Printing

5️⃣ Software

  • System Software: OS(MS-DOS,Windows,Linux,Unix), Device Drivers, Language Translators(Assembler/Compiler/Interpreter — देखें तुलना तालिका ऊपर), Linker, Loader
  • Application Software: General(Word,Excel,PowerPoint,DBMS,DTP,Graphics,Multimedia) vs Specific Purpose(Inventory,Payroll,Hotel,Reservation)
  • System Utilities: Disk Compression, Defragmenter, Backup, Disk Cleaner, Anti-virus
  • Licenses: Open Source(GPL,MIT) · Proprietary · Freeware · Shareware · Commercial · Public Domain · Copyleft

6️⃣ Number System

  • Base: Binary=2(0,1) · Octal=8(0-7) · Decimal=10(0-9) · Hexadecimal=16(0-9,A-F)
  • Digital Computer केवल Binary समझता है (Electronic Switch ON/OFF)
  • Conversion Rules — देखें ऊपर 🧮 अनुभाग
  • Codes: BCD(हर decimal digit=4 bits, IBM) · ASCII-7(128 chars) · ASCII-8/Extended(256) · EBCDIC(IBM,8-bit,256) · Unicode(16-bit, गैर-अंग्रेज़ी भाषाएँ)
  • Logic Gates: AND(दोनों True तभी True) · OR(कोई एक True) · NOT(उल्टा) · NAND(AND का उल्टा) · NOR(OR का उल्टा) · XOR(केवल एक True) · XNOR(दोनों समान)
  • IC Classification (Gate count): SSI(1-10) · MSI(10-100) · LSI(100-1000) · VLSI(1000+) · ULSI(5th Gen)
