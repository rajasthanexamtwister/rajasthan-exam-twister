📚 Topic-wise Revision

1. विवाह रस्में (क्रमानुसार)

बिंदोली (निमंत्रण) → बनवारा/बान (हल्दी-उबटन) → चिकनी कोथली (सगाई उपहार) → बरी-पड़ला (वस्त्राभूषण+मेवे) → सामेला (स्वागत) → जांनोटण (वर पक्ष भोज) → टीका/मूठ भराई (मांगलिक रस्में) → फेरे (झिम्मी ओढ़नी) → ढुकाव → बढ़ार (दूसरे दिन प्रीतिभोज) → आणौ/गौना/मुकलावा (विदाई) → टूटिया (बाद में स्वांग)

2. मृत्यु संस्कार (क्रमानुसार)

जौसर (जीवित का स्वयं भोज, वैकल्पिक) → अंत्येष्टि → बैकुण्ठी (अर्थी) → पानीवाड़ा (स्नान) → आघेटा/सातरवाड़ा/बखेर (शोक रस्में) → मोकाण → पाग-दस्तूर (उत्तराधिकार) → मौसर (मृत्यु भोज)

3. जन्म संस्कार (क्रमानुसार)

अगरणी/सीमन्तोन्नयन (गर्भकाल) → जन्म → जलवा (कुआँ पूजा) → जामणा (ननिहाल उपहार, प्रथम पुत्र) → दसोटण (10वाँ दिन शुद्धि) → जडूला (मुंडन) → उपनयन/यज्ञोपवीत (जनेऊ)

4. सामाजिक कुप्रथाएँ व सुधार क्रम (कालानुक्रम)

बूंदी सती रोक (1822) → बीकानेर सती रोक (1825) → ब्रिटिश भारत सती प्रतिबंध (1829) → अलवर सती रोक (1830) → कोटा मानव-व्यापार रोक (1831) → कोटा कन्या वध रोक (1833) → बूंदी कन्या वध रोक (1834) → जोधपुर त्याग प्रथा रोक (1841) → जयपुर/डूंगरपुर सती रोक (1844) → उदयपुर डाकन प्रथा रोक (1853) → मेवाड़ सती रोक (1861) → देश-हितेषणी सभा (1877) → शारदा एक्ट (1929, लागू 1930) → सागड़ी निवारण अधिनियम (1961) → देवराला कांड (1987) → राजस्थान सती अधिनियम लागू (1988) → बाल विवाह निषेध अधिनियम (2006) → Witch Hunting Act (2015)

5. जनजातीय प्रथाएँ

गरासिया विवाह प्रकार (मोर बांधिया, पहरावणा, ताणना, मेलबो, खेवणा/नाता, सेवा) | सांसी — कूकड़ी रस्म

6. दास प्रथा / राजमहल शब्दावली

राजलोक (दासी विभाग) → पड़दायत (उपपत्नी) → पासवान/खवासन (सम्मानित दासी) → गोला (दास) → सागड़ी (बंधुआ मजदूरी)
