🚨 Mistake / Answer-Key Bug Database ▼

MongoDB written in? — Book/Answer-key says "All of the mentioned". Verified correct: C++ (MongoDB's core DB engine is implemented in C++; JS is only used for shell/scripting). Answer Key Bug If "C++" is an available option in the real exam, choose that.
Point Guard → Hockey? — Wrong pairing. Point Guard belongs to Basketball, not Hockey.
"Paging requires contiguous allocation" — False. Paging's whole advantage is non-contiguous allocation; this is what removes external fragmentation.
"HTTPS is faster than HTTP" — False. Encryption overhead makes HTTPS marginally slower; its benefit is security, not speed.
"DFS not applicable to cyclic graphs" — False. DFS works on cyclic graphs too, provided a visited array is maintained (else infinite loop).
Function Overloading by Return Type alone — Invalid. Overloading needs different parameter lists; changing only return type does not create a valid overload.

🔢 Number System ▼

⭐⭐⭐⭐⭐ BCI's single most favourite topic.

Decimal → Binary → Hex

Decimal 15 → Binary 1111 → Hex F

Decimal Fraction → Binary (e.g. 26.85)

Integer part: repeated ÷2, read remainders bottom→top: 26 → 11010

Fraction part: repeated ×2, take integer digit each time: 0.85 → 110110 (approx)

Final: 26.85₁₀ ≈ 11010.110110₂

🧠 Trick: Integer part → divide by 2 (remainder bottom to top). Fraction part → multiply by 2 (carry digit top to bottom) until required bits.

💾 Memory: SRAM vs DRAM ▼

SRAMDRAM
FasterSlower

🧠 S = Speed, D = Dynamic (needs Refresh)

⭐⭐⭐ First commercial computer: UNIVAC I (ENIAC = first general-purpose electronic digital computer, military use; Z3 = first programmable computer).

⭐⭐⭐ Register operations are called Micro-operations (types: Register Transfer, Arithmetic, Logic, Shift).

⭐⭐⭐ Multiple instructions executed in one clock cycle on a single core = Superscalar Execution (not Pipelining — pipelining overlaps stages, doesn't fully execute multiple instructions per cycle).

🖥️ Operating System ▼

Paging

  • ✅ Eliminates External Fragmentation
  • ✅ Causes Internal Fragmentation (last page not fully filled)
  • ✅ Uses Logical Address → Page Table → Physical Address
  • ❌ Does NOT require contiguous allocation (its main benefit)
🧠 Paging: ❌External Frag, ✅Internal Frag, ❌Contiguous

Deadlock

4 Necessary Conditions — trick M H N C:

  1. Mutual Exclusion
  2. Hold and Wait
  3. No Preemption
  4. Circular Wait
  • Banker's Algorithm → Deadlock Avoidance
  • Resolution can be via Termination or Resource Preemption — termination is not always required

Match: OS Concepts

ConceptPurpose
SemaphoreSynchronize access to shared resources
MutexExclusive access to Critical Section
Virtual MemorySimulates larger memory using disk
ThrashingExcessive Paging reduces performance

🌐 Computer Networks ▼

TCP Features

  • ✅ Connection-Oriented
  • ✅ Reliable (ACK + retransmission)
  • ✅ Flow Control (Sliding Window)
  • ❌ NOT low overhead — header is 20 bytes vs UDP's 8

Three-way Handshake

SYN → SYN+ACK → ACK

TCP Flags (trick: UAPRSF)

URG, ACK, PSH, RST, SYN, FIN

IPv6

  • 128-bit address, 8 blocks × 16 bits
  • Header Extension supported
  • Supports Multicast (no Broadcast)
  • No header checksum
  • Better security (IPSec)

HTTP vs HTTPS

  • HTTP sends plain text (Port 80)
  • HTTPS encrypts data via SSL/TLS (Port 443)
  • ❌ HTTPS is NOT faster (encryption overhead)
🧠 HTTP=80, HTTPS=443, S=Secure

🧩 OOP / C++ ▼

Overloading vs Overriding

OverloadingOverriding
Same classParent + Child class
Compile time (Static Polymorphism)Run time (Dynamic Polymorphism)
Different parameters, same nameSame name + same parameters

❌ Overloading cannot be achieved by changing only return type.

Method Overriding rules

  • Name, parameters, return type (or covariant) must match
  • Access modifier in child ≥ parent (cannot reduce visibility)
  • Static, Final, Private, Constructor → cannot be overridden

Operator Overloading

Possible: + - * [] () << >>. Cannot overload: . :: ?: sizeof

ConceptUsage

C23 Standard

Type-safe Null Pointer Constant added in C23: nullptr (and nullptr_t) — previously only in C++, now added to C too.

Control Structures (C)

  • switch without default is still valid (default is optional)
  • for loop → best when iterations are known in advance
  • while loop → executes 0 or more times

🌳 Data Structures ▼

Tree Traversals

TraversalOrderUse
InorderL N RAlways sorted in BST
PreorderN L RRoot visited first — copy/serialize tree
PostorderL R NRoot last — expression evaluation, delete tree
Level OrderBFS-basedLevel by level

Constructing a tree

  • Root of a subtree = first element of its Preorder segment (or last of Postorder)
  • Use Root to split the Inorder sequence into Left/Right subtrees, recurse
  • Inorder+Preorder → unique tree ✅; Inorder+Postorder → unique tree ✅; Preorder+Postorder alone → NOT unique ❌

Expression Tree example

     +
   /   \
  *     5
 / \
3   4

Postorder evaluation: 3 4 * 5 +

BST

Average search: O(log n), Worst case: O(n). Self-balancing variants: AVL Tree, Red-Black Tree. Heap = Complete Binary Tree.

Huffman Coding

⭐⭐⭐⭐⭐⭐ Greedy algorithm, uses Priority Queue (Min Heap), complexity O(n log n). Used for Lossless Compression (ZIP, PNG, MP3, PDF, text).

Steps: build leaf nodes for each symbol → put in priority queue → repeatedly combine two lowest-frequency nodes → repeat until one tree remains. Property: low frequency → long code, high frequency → short code (Prefix Code — no code is a prefix of another).

Complete Undirected Graph edges = n(n−1)/2. Complete Directed Graph edges = n(n−1).

🕸️ Graph Algorithms ▼

Minimum Spanning Tree (MST)

Edges in MST = Vertices − 1. No cycles. Requires a connected graph. Algorithms: Kruskal (sorts edges, uses Union-Find) and Prim (grows from a vertex, uses Priority Queue).

Shortest Path Algorithms

Y2K Bug

Full form: Year 2000 Problem. Cause: old programs stored year in 2 digits, so "00" was read as 1900 instead of 2000. Fix: switch to 4-digit years. Related: 2038 Problem (Unix time overflow), Leap Year logic (2000 was a leap year, 1900 was not).

🧩 Reasoning ▼

Coding-Decoding

Common pattern: first and last letters stay fixed; the middle letters get rearranged in a set pattern. Example: GOLDEN → GLEODN (first G, last N fixed; middle OLDE → LEOD rearranged).
