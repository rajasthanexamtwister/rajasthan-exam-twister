#कहावत / मुहावरा❌ मेरी गलती✅ सही अर्थ🧠 ट्रिक
1अंधाधुंध की साहबी, घटाटोप को राजअज्ञातविवेकहीन शासकों का शासनअंधाधुंध = बिना विवेक → अव्यवस्था
2अठे किसा काचर खाच हैअज्ञातयहाँ दाल नहीं गलेगीकाचर खाच = दाल नहीं गलेगी
3ओस चाट्यां कसो पेट भरैअज्ञातनिरर्थक प्रयास / अपर्याप्त साधनों से सफलता नहींओस = बहुत कम → पेट नहीं भरता
4कामेड़ी बाज नै कोनी जीतेअज्ञातकमजोर शक्तिशाली को नहीं जीत सकताबाज = शक्तिशाली पक्षी
5दमड़ी री डोकरी नै टकौ सिर मुंडाई रौअज्ञातकम मूल्य की वस्तु पर अधिक खर्चदमड़ी < टका → व्यर्थ खर्च
6दांतां लोही लागणौअज्ञातआदत पड़ जाना (लत लगना)लोही (खून) लगना = आदत/लत

#कहावत / मुहावरा❌ ट्रैप विकल्प✅ सही अर्थ🧠 ट्रिक
1दूबला नै दो असाढ़सुख मिलनाआपत्ति पर आपत्ति आनादूबला + दो असाढ़ = दोहरी मुसीबत

🧠 मेमोरी ट्रिक्स और स्मरण-सूत्र

💡 शब्द-आधारित ट्रिक्स
  • बावै = बोना → फल काटना = कर्म का फल
  • लोही = खून/स्वाद → आदत/लत = दांतां लोही लागणौ
  • तेल नहीं = क्षमता नहीं = आँ तिलां मैँ तेल कोनी
  • काचर खाच = दाल नहीं गलेगी = अठे किसा काचर खाच है
  • डागलां = पैर/दौड़ → झूठ लंबे समय तक नहीं दौड़ता
  • दूबला + दो = दोहरी मुसीबत
💡 चित्र-आधारित ट्रिक्स
  • दूज का चाँद = बहुत पतला → बहुत कम दिखता है = दुर्लभ
  • कबूतर + कुआँ = कबूतर को केवल अपना कुआँ दिखता है = स्वार्थ
  • ऊँट + बाज = बाज शक्तिशाली = कमजोर नहीं जीत सकता
  • सोना = शुद्ध → कलंक नहीं लगता
  • थोथा चना = खाली = बाजे की आवाज तेज = अधूरा ज्ञान अधिक बोलता है
  • ओस = बहुत कम → पेट नहीं भरता = निरर्थक प्रयास
🧠 समूह स्मरण (एक भाव — कई कहावतें)
एकता: एक नै एक इग्यारै · पाँच आंगलियां पूंच्यौँ भारी · दोन्यू हाथ मिलायां ई धुपै
अनुभव: घाट-घाट रौ पांणी · ठोकर खार हुंस्यार · घिस-घिस नै गोळ होणौ
कर्म: बावै सो लूणै · आप कमाडा कामडा · नीत गैल बरकत
