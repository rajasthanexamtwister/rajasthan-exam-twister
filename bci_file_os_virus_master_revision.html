1. 🚨 मेरी गलतियाँ / ट्रैप (Merged — Repeats Removed)

Vector नहीं है → JPEG (Raster है)। Vector: AI, SVG, EPS, CDR, WMF, APM, PDF(partial)।
Access DB Extension → पुराना .mdb, नया (2007+) .accdb। ("dpf/rdb/xls" ट्रैप में न फंसें)
DOS Filename Rule → 8.3 = मुख्य नाम अधिकतम 8, Extension अधिकतम 3 Characters। ("5" या "4" ट्रैप विकल्प गलत)
Booting का अर्थ → Computer को Start/Restart करना (न कि Install/Scan/Shutdown)।
Delete की गई File → पहले Recycle Bin में जाती है; Shift+Delete = Permanent।
Command Interpreter → Shell कहलाता है (Kernel नहीं)।
FAT का पूरा नाम → File Allocation Table (Attribute Table नहीं)।
Bootstrap → परीक्षा में प्रायः Cold Boot माना जाता है (तकनीकी रूप से यह पूरी booting process को भी कहते हैं — पर उत्तर हेतु Cold Boot याद रखें)।
Single User OS → MS-DOS (Windows/Mac/Linux Multi-user support रखते हैं)।
Windows 1.0 → 1985 में आया (1990 = Windows 3.0 — ट्रैप)।
Windows 64-bit Support → Windows XP (x64 Edition) से शुरू।
Windows 7 Default File System → NTFS (EXT = Linux, BSD/UFS = Unix — Windows 7 डिफ़ॉल्ट रूप से नहीं पढ़ता)।
File Permission Command (Linux) → chmod (Change Mode); cd=Change Directory, echo=Print।
OS Classification में गलत विकल्प → "Time-Batch Processing OS" — यह कोई मान्य Classification नहीं (Batch OS और Time-Sharing OS अलग-अलग असली Types हैं)।
RTOS पहचान संकेत → प्रश्न में "Critical Response Time / Deadline / Millisecond" दिखे तो उत्तर = Real-Time OS।
Digital Signature क्या नहीं देता → Confidentiality नहीं देता (वह केवल Encryption से मिलती है)। देता है: Integrity, Authentication, Non-repudiation (Trick: AIN)।
Recovery Technique नहीं है → "Recovery Management" (असली techniques: Immediate Update, Deferred Update, Two-Phase Commit)।
RPO vs RTO → RPO = अधिकतम स्वीकार्य Data Loss (Point); RTO = अधिकतम Recovery Time।
Trojan Horse → Self-Replicate नहीं करता (यह Virus/Worm की विशेषता है) — Assertion-Reason प्रश्नों में बार-बार ट्रैप।
Malware Definition → User की "पर्याप्त सहमति" से इंस्टॉल होने की बात गलत है — Malware सामान्यतः धोखे/बिना पूरी जानकारी के इंस्टॉल होता है।
Full Backup → सबसे अधिक Storage Space लेता है (Incremental सबसे कम, Differential मध्यम)।
Independent Malicious Program (Host चाहिए नहीं) → Worm (Trojan को host चाहिए app के रूप में, Virus को host file चाहिए)।

4. 📚 Operating System — विषयवार रिवीजन

⭐ Core Facts

  • पहला Operating System → 1950 (परीक्षा उत्तर अनुसार)
  • DOS File Name → अधिकतम 8 Characters (+3 Extension = 8.3 Rule)
  • Windows पहली बार → 1985 (Windows 1.0)
  • Notepad Extension → .txt
  • Command Interpreter → Shell
  • FAT → File Allocation Table
  • BIOS → Boot Process शुरू करता है, प्रयोगकर्ता OS
  • Booting → Computer Start/Restart करना
  • Deleted File → पहले Recycle Bin में जाती है
  • Linux → Open-Source Operating System
  • DSM → Distributed Shared Memory
  • Bootstrapping → Cold Boot (परीक्षा उत्तर)
  • Single User OS → MS-DOS
  • Windows 64-bit Support → Windows XP से
  • Client-Server Network OS → Windows 2000
  • Taskbar → स्क्रीन के सबसे निचले भाग में
  • OS = User व Hardware के बीच Interface (मध्यस्थ)
  • Bootstrap Loader का पहला Instruction → BIOS में संग्रहीत
  • Batch OS → समान Jobs को Group बनाकर Execute करता है
  • Device Driver → OS का वह भाग जो विशिष्ट Hardware से Interact करता है
  • Memory Management → हर Memory Allocation का Track रखता है
  • CLI → Terminal/Console में Command टाइप कर OS से Interaction
  • GUI + Multiuser + Multitasking OS → Red Hat Linux / Windows XP प्रकार
  • GUI संचार → Icons के माध्यम से

🧠 OS Classification (सभी Valid Types)

  • Batch OS — समान Jobs Group में Execute
  • Multiprogramming OS — RAM में कई Programs, CPU हमेशा Busy
  • Multitasking OS — एक User, कई Task साथ (Time Sharing)
  • Multithreading — एक Program के कई Threads Parallel
  • Multiprocessing — कई CPU/Cores
  • Time-Sharing OS — कई Users एक CPU Share करते हैं
  • Distributed OS — कई Computers मिलकर एक System जैसे
  • Network OS — Server-Client Model
  • Real-Time OS — Deadline Fixed/Critical
"Time-Batch Processing OS" — यह कोई मान्य वर्गीकरण नहीं (Batch OS और Time-Sharing OS को गलत तरीके से जोड़कर Trap बनाया जाता है)।

⭐⭐⭐⭐⭐ Digital Signature

देता है: Authentication, Integrity, Non-repudiation (Trick: AIN)। नहीं देता: Confidentiality (वह केवल Encryption से मिलती है)।
