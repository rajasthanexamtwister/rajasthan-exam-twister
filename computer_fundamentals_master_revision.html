📌 अन्य High-Yield Facts

  • FAT32 की Max Single File Size = 4 GB (Partition अलग बात है) ⭐
  • CPU डेटा चाहिए तो सबसे पहले Cache Memory Check करता है ⭐⭐
  • Magnetic Disk Coating = Iron Oxide
  • Booting Instructions = ROM/BIOS में Store
  • Tertiary Storage = Robotic Arm द्वारा Tape/Optical Library Connect करना
  • Register = Flip-Flops का Collection
  • Formatting = Disk को Tracks + Sectors में व्यवस्थित करना
  • SSD = Fastest Secondary Storage, No Moving Parts
  • HDD Failure Symptoms = Clicking Sound, Slow Performance, Bad Sectors
  • Disk का गोलाकार Data-लेखन भाग = Track; Track के टुकड़े = Sector (≈512 Bytes)

⚡ Rapid Revision — One-Liners (Memory)

  • MAR = Address | MDR = Data
  • Register > Cache > RAM > SSD > HDD
  • Buffer = Temporary Holding Area
  • Cache = CPU ↔ RAM (SRAM आधारित)
  • ROM = Firmware/Non-Volatile | RAM = Volatile/Temporary
  • Register = Flip-Flops का समूह
  • Tertiary Storage = Robotic Arm
  • Formatting = Tracks + Sectors
  • Bit = सबसे छोटी Data Unit | Nibble = 4 Bits | Byte = 8 Bits
  • FAT32 = Max File 4 GB
  • Paging = Non-Contiguous | Swapping = RAM↔Disk | Spooling = Printer Queue
  • 1 KB=1024B, 1 MB=1024KB, 1 GB=1024MB, 1 TB=1024GB, 1 PB=1024TB

📌 Computer Categories

  • कार्यप्रणाली आधार पर: Analog, Digital, Hybrid (कोई "Hydrobrid" नहीं होता ❌)
  • Hybrid Computer उपयोग: Radar, Air Traffic Control, Medical Instruments
  • आकार आधार पर: Micro, Mini, Mainframe, Super (Optical Computer यह Category नहीं है)
  • Parallel Computing = एक Processing Technique है, Computer Category नहीं
  • Mainframe/Supercomputer Access = Terminal के माध्यम से
  • Supercomputer Speed मापने की इकाई = FLOPS (MIPS पुरानी/बंद इकाई)
  • Supercomputer का Traditional Use = Scientific & Engineering Calculations

📌 Basic Concepts

  • CPU = कंप्यूटर का मस्तिष्क (Brain)
  • Processed Data → Information (सामान्य Concept) | IPO Cycle में अंतिम परिणाम → Output ⚠ Frequently Confused
  • Computer अपनी स्वयं की Intelligence नहीं रखता (Intelligence = शून्य)
  • Diligence = बिना थके बार-बार एक ही कार्य करने की क्षमता
  • Versatility = विभिन्न प्रकार के कार्य करने की क्षमता
  • Storage Capacity = Program/Data संग्रहित करने की क्षमता
  • Chips बनाने की सामग्री = Semiconductor
  • अचानक Computer बंद होना = Crash
  • Computer System = Hardware + Software
