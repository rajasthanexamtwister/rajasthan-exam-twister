🚨 MY EXAM TRAPS & CONFUSIONS

TRAP 1 — Memory Type
Q: Volatile memory kaun si hai?
✅ RAM (power off → data gone)
❌ ROM, HDD, SSD — ye non-volatile hain
Logic: RAM = temporary workspace. Bijli gayi, sab gayi.
TRAP 2 — Memory Units
Q: 1024 Bytes = ?
✅ 1 KB (Kilobyte)
❌ 1 GB — bohot common galti!
Logic: Bit → Nibble(4) → Byte(8) → KB(1024B) → MB → GB → TB → PB → EB → ZB → YB
TRAP 3 — OS vs Application Software
Q: Word Processing, Spreadsheet, Photo Editing kis software ke example hain?
✅ Application Software
❌ System Software — OS nahi hai ye!
Logic: OS = Windows/Linux. MS Word, Excel, Photoshop = Application.
TRAP 4 — System Software Mein Kya Nahi
Q: Desktop Publishing (DTP), Database Software — System Software hai?
✅ Nahi — ye Application Software hain
❌ System Software includes: OS, Device Driver, Utility, Language Translator
Logic: DTP (PageMaker, Corel) user ke liye hai = Application.
TRAP 5 — Impact vs Non-Impact Printer
Q: Laser Printer kis category mein?
✅ Non-Impact (koi contact nahi, toner use karta hai)
❌ Dot Matrix, Daisy Wheel, Drum = Impact printers
Logic: Impact = dhaka deta hai paper ko. Laser/Inkjet = nahi deta.
TRAP 6 — Plotter Input hai ya Output?
Q: Plotter kya hai?
✅ Output Device — large CAD drawings, maps print karta hai
❌ Input Device — bilkul nahi!
Logic: Plotter pen use karke lines draw karta hai — Output.
TRAP 7 — Browser vs Email vs Search Engine
Q: Gmail web browser hai?
✅ Nahi — Gmail = Email Service
❌ KompoZer bhi browser nahi — HTML editor hai
Logic: Browser = Chrome, Firefox, Safari, Opera, Edge. Gmail browser ke andar chalta hai.
TRAP 8 — Booting Sequence
Q: Computer ON hone par sabse pehle kya load hota hai?
✅ BIOS (ROM mein store hai)
❌ OS nahi, Driver nahi — pehle BIOS, phir OS
Logic: BIOS → POST → OS Load (Booting). BIOS ROM ka hissa hai.
TRAP 9 — ICT vs IT
Q: ICT = IT ka subset hai?
✅ Galat — IT ICT ka subset hai (ICT bada concept hai)
❌ Software use rights = License, Copyright nahi exactly
Logic: ICT = IT + Communication technology. IT = iska ek hissa.
TRAP 10 — Antivirus vs OS Confusion
Q: Fedora, Linux — Antivirus hai?
✅ Nahi — ye Operating Systems hain
❌ Antivirus = Avast, Norton, Kaspersky, McAfee, AVG, NOD32
Logic: Linux ek OS hai, virus se protect nahi karta directly.
TRAP 11 — Open Source Nahi Hai
Q: Open Source nahi hai?
✅ Adobe Photoshop = Proprietary (Paid)
❌ Linux, Firefox, LibreOffice, Ubuntu, WordPress = Open Source hain
Logic: "Free to use and modify" = Open Source. Adobe = pay karno.
TRAP 12 — GUI Use Kya Nahi Karta
Q: GUI interface mein kya use nahi hota?
✅ Graphs — GUI mein Icons, Menus, Colors use hote hain
❌ MS-DOS = GUI nahi, CUI (Command Line) hai
Logic: GUI = Windows/Mac/Android style. DOS = text commands.
TRAP 13 — Hard Disk Cylinder Count
Q: 10 surfaces, har surface mein 5 tracks → kitne cylinders?
✅ 5 Cylinders (same track number = 1 cylinder)
❌ 50 nahi (surfaces × tracks = cylinders count is tracks per surface)
Logic: Cylinder = ek hi track number sab surfaces par. Tracks count = Cylinder count.
TRAP 14 — Nibble vs Byte
Q: Computer ki sabse chhoti unit?
✅ Bit (0 ya 1)
❌ Nibble = 4 bits, Byte = 8 bits — ye chhoti units hain lekin Bit sabse chhhoti
Logic: Bit → Nibble(4) → Byte(8). Nibble sabse chhoti nahi, Bit hai.

Memory Unit Conversion — Quick Calc

Formula Chain: 8 Bits = 1 Byte → ×1024 each step
Byte → KB → MB → GB → TB → PB → EB → ZB → YB

Powers of 2: 2¹⁰=1024(KB) | 2²⁰=1MB | 2³⁰=1GB | 2⁴⁰=1TB | 2⁵⁰=1PB

Common exam Qs: 1 Petabyte = 1024 TB | 1 Yottabyte = 1024 ZB | 1 ZB = 1024 EB
