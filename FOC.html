TRAP 1 — Volatile Memory
ROM, HDD, SSD = Volatile
बिजली जाने पर ये data रखते हैं
✅ सही
RAM = Volatile (बिजली गई → data गया)
ROM/HDD/SSD = Non-Volatile
TRAP 2 — Memory Units
1024 Bytes = 1 GB
बहुत common गलती — GB बहुत बड़ा unit है
✅ सही
1024 Bytes = 1 KB
Chain: Bit→Nibble(4b)→Byte(8b)→KB→MB→GB→TB
TRAP 3 — Application vs System Software
Word, Excel, Photoshop = System Software
System Software = OS, Driver, Compiler
✅ सही
Word Processing, Spreadsheet, Photo Editing = Application Software
TRAP 4 — System Software में क्या नहीं?
DTP (PageMaker, Corel) = System Software
DTP user के लिए है, OS नहीं
✅ सही
DTP / Database = Application Software
System = OS, Driver, Utility, Language Translator
TRAP 5 — Impact vs Non-Impact Printer
Laser Printer = Impact
Laser में paper को छूता नहीं — toner use होता है
✅ सही
Laser = Non-Impact
Impact = Dot Matrix, Daisy Wheel, Drum, Chain
TRAP 6 — Plotter Input या Output?
Plotter = Input Device
Plotter pen से lines draw करता है — produce करता है
✅ सही
Plotter = Output Device
Large CAD drawings, Maps, Engineering diagrams
TRAP 7 — Browser vs Email
Gmail = Web Browser
Gmail browser के अंदर चलता है, खुद browser नहीं है
✅ सही
Gmail = Email Service
Browser = Chrome, Firefox, Safari, Edge, Opera
KompoZer = HTML Editor (Browser नहीं)
TRAP 8 — Booting Sequence
Computer ON होने पर पहले OS load होता है
BIOS ROM में store रहता है, OS से पहले चलता है
✅ सही
क्रम: BIOS → POST → OS Load
BIOS = ROM का हिस्सा है
TRAP 9 — ICT vs IT
IT = ICT का बड़ा version / ICT = IT का subset
✅ सही
ICT बड़ा है → IT उसका subset है
ICT = IT + Communication Technology
TRAP 10 — OS vs Antivirus
Fedora, Linux = Antivirus
Linux एक OS है, virus से directly protect नहीं करता
✅ सही
Fedora, Linux = Operating System
Antivirus = Avast, Norton, Kaspersky, McAfee, AVG, NOD32
TRAP 11 — Open Source नहीं है
Adobe Photoshop = Open Source
Adobe = Proprietary / Paid software
✅ सही
Open Source = Linux, Firefox, LibreOffice, Ubuntu, WordPress, GIMP
Adobe Photoshop = Proprietary ❌
TRAP 12 — GUI में क्या use नहीं होता?
GUI में सब कुछ होता है
GUI = Icons, Menus, Colors — Graphs नहीं
✅ सही
GUI में Graphs use नहीं होते
MS-DOS = GUI नहीं, CUI (Command Line) है
TRAP 13 — Hard Disk Cylinders
10 surfaces × 5 tracks = 50 cylinders
Cylinder = same track number सभी surfaces पर
✅ सही
10 surfaces, 5 tracks प्रति surface = 5 Cylinders
(Cylinder count = Tracks per surface)
TRAP 14 — Computer की सबसे छोटी unit
Nibble / Byte = सबसे छोटी unit
Nibble=4bits, Byte=8bits — दोनों Bit से बड़े हैं
✅ सही
Bit (0 या 1) = सबसे छोटी unit
Bit → Nibble(4) → Byte(8)

🧠 Memory पदानुक्रम — Speed & Classification

Speed (तेज़ → धीमा): Register → Cache → RAM → SSD → HDD → Magnetic Tape
Size (छोटा → बड़ा): Register → Cache → RAM → HDD
Unit Chain: Bit → Nibble(4b) → Byte(8b) → KB(1024B) → MB → GB → TB → PB → EB → ZB → YB
Memoryप्रकारVolatile?मुख्य तथ्य
RegisterPrimaryहाँसबसे तेज़, CPU के अंदर, Flip-Flops से बना
Cache (L1/L2/L3)PrimaryहाँCPU + RAM के बीच buffer, SRAM से बना
RAMPrimaryहाँWorking memory, DRAM (Capacitor-based)
ROMPrimaryनहींBIOS store करता है, Read Only, Non-Volatile
HDDSecondaryनहींAluminium + Iron Oxide platter, RPM से speed
SSDSecondaryनहींFlash Memory, HDD से तेज़, कोई moving part नहीं
CD-RSecondaryनहींWrite Once Read Many (WORM)
DVDSecondaryनहीं4.7 GB (single layer), 8.5 GB (dual layer)
Magnetic TapeSecondaryनहींSequential access, सबसे धीमा, Backup के लिए

🔢 Memory Unit Conversion — Formula Sheet

Chain: 8 Bits = 1 Byte  →  ×1024 हर step पर
Byte → KB → MB → GB → TB → PB → EB → ZB → YB

Powers of 2:  2¹⁰ = 1 KB  |  2²⁰ = 1 MB  |  2³⁰ = 1 GB  |  2⁴⁰ = 1 TB  |  2⁵⁰ = 1 PB

1 GB (Gigabyte)1024 MBMovie ≈ 1–2 GB
