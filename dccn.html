Exam Traps & Confusions — Rajasthan BCI PYQ based
Trap 1 — IPv4 Packet with IHL = 2 (8 bytes)
IPv4 header ki minimum length = 20 bytes (IHL = 5). Agar IHL = 2 given ho (8 bytes), toh receiver packet ko Reject (Discard) karega. Answer hoga — "receiver rejects the packet" — not "hops = 2".
Trap 2 — Checksum ka kaam
Checksum sirf Error Detection karta hai — Error Correction NAHI. CRC bhi sirf Detection. ARQ/Hamming Code = Correction. Yeh confusion bahut common hai.
Trap 3 — Firewall (Network Layer) = Packet Filter
Network Layer Firewall content nahi padhta — sirf IP Address aur Port Number pe packet filter karta hai. Content inspection = Application Layer Firewall (WAF).
Trap 4 — MAC vs IP Address confusion
MAC Address = 48-bit (6 bytes) hexadecimal — NIC ka Physical/Hardware address. Pehle 3 bytes = OUI (Manufacturer). IP Address = Logical address (IPv4=32-bit, IPv6=128-bit). MAC change nahi hota, IP change ho sakta hai.
Trap 5 — WiFi vs WiMAX standard confusion
WiFi = IEEE 802.11 = Radio Waves = LAN. WiMAX = IEEE 802.16 = Spectrum = Broadband Wireless (MAN range). Exam mein "IEEE 803.16y" diya tha — yeh GALAT hai, sahi = IEEE 802.16.
Trap 6 — HTTP ka Email use nahi hota
HTTP = Web pages only. Email send = SMTP (Port 25). Email receive = POP3 (Port 110) ya IMAP (Port 143). HTTP email protocol NAHI hai — yeh answer galat option hai.
Trap 7 — Switch kya reduce karta hai?
Switch Bandwidth improve karta hai aur Collision bhi reduce karta hai (CSMA/CD se better). Notes mein Ans = (a) Bandwidth, lekin technically "Both (a) and (b)" sahi hota hai. BCI paper mein jo option zyada specific lage woh choose karo.
Trap 8 — LAN "Large Area Network" NAHI hai
LAN = Local Area Network. Patwar Exam 2025 mein "Large Area Network" option diya tha — yeh GALAT hai. Woh "not a type of network" option tha.
Trap 9 — OSI first layer (bottom) = Physical, NOT Application
OSI model: Layer 1 = Physical (lowest/first). Layer 7 = Application (topmost). Exam mein "first layer" puchha jata hai — always Physical Layer answer karo.
Trap 10 — PING uses ICMP, not TCP/UDP
PING = ICMP (Internet Control Message Protocol) Echo Request/Reply. Host alive check karna = PING command. Telnet = remote login, IPConfig = IP settings dekhna.
Trap 11 — Router kaunse OSI layer pe?
Router = Network Layer (Layer 3) = IP Address based. Switch/Bridge = Layer 2. HUB = Layer 1. Gateway = All 7 Layers. "Switch generally operates in Physical, Data Link and Network" — yeh Bridge ke baare mein galat likha tha notes mein. Switch = strictly Layer 2.
Trap 12 — Data Communication component mein Scanner NAHI hai
Data Communication ke 5 components: Message, Sender (Source), Medium (Transmission System), Receiver, Protocol. Scanner is NOT a component — Raj Police Telecom 2025 mein yeh trap tha.
OSI Model — Open System Interconnection (ISO, 1984)
OSI = 7-layer Architecture Model — ISO dwara 1984 mein design kiya. Yeh sirf Reference/Framework hai, actual protocol nahi. Computer ko aapas mein Transmit karne ki prakriya ko 7 layers mein define karta hai.

Physical Layer ke kaam
  • Data Encoding
  • Bit Synchronization
  • Bit Rate Control
  • Encoding — Manchester, Differential Manchester
  • Transmission Medium — Wire based, Wireless
  • Line Configuration — Point-to-Point, Broadcast
  • Network Topologies define karna
  • Transmission Modes — Simplex, Half Duplex, Full Duplex
Physical Layer components
  • Cable, Repeater, HUB, Modem

  • Bit Synchronization = Transmission rate align karna
  • Layer 1 = bits (0s and 1s)
  • Electrical/Optical/Mechanical interface define karta hai
OSI Stack kaise kaam karta hai
Encapsulation (Sender side): Layer 7 se Layer 1 tak — har layer apna Header add karta hai. De-encapsulation (Receiver side): Layer 1 se Layer 7 tak — har layer apna header remove karta hai. Data structure = Stack (LIFO — Last In First Out).

Device Details
NIC (Network Interface Card)
  • Alias: LAN Card, Ethernet Card, Network Adapter, Connection Card
  • MAC Address = 48 bits (6 bytes) — unique hardware address
  • Pehle 3 bytes = OUI (Manufacturer ID)
  • Physical + Data Link Layer dono pe kaam karta hai
  • Types: Ethernet NIC (1980, Robert Metcalf) | Wireless NIC (Wi-Fi, WAP)
  • Features: I/O Interrupt, Direct Memory Interface, Data Transmission
HUB — Types
  • Passive HUB = Dumb — sirf wiring connector — no feature
  • Active HUB = Additional intelligence — signal amplify karta hai
  • Intelligent HUB = Advance — Management Software included — N/W problems analyze karta hai
  • HUB = Multiport device — LAN mein sab nodes ko ek point pe jodhta hai
  • HUB data filter nahi karta — broadcast karta hai
Modem (MOdulator-DEModulator)
  • Modulation = Digital signal → Analog signal (Telephone line ke liye)
  • Demodulation = Analog signal → Digital signal (Receive karte time)
  • Modulation types: AM (Amplitude), FM (Frequency), PM (Phase)
  • Telephone line aur Computer ke beech jodha jaata hai
  • N/W mein Transmitter + Receiver dono ka kaam karta hai
Router — Types
  • Wireless Router = Wi-Fi provide karta hai (WAP)
  • Core Router = N/W ke andar routing
  • Edge Router = N/W ki boundary pe — low capacity
  • Brouter = Bridge + Router combined
  • Broadband Router = High speed connectivity
  • IP Address use karke best path find karta hai
  • Routing Protocols use karta hai — Datapacks forward karta hai

Twisted Pair Cable
  • 2 insulated copper wires twisted together
  • Sabse sasta aur common — short distance
  • UTP: No outer grounding cable needed — max 1024 nodes
  • STP: Outer metallic shield — less noise — max 270 nodes
  • Coaxial se less noise resistant
  • RJ45 connector = 4 pairs (8 wires) — UTP cable
Coaxial Cable
  • Central copper conductor → Core
  • Dielectric plastic coating pe wrap hota hai
  • Outer conductor (metal shield) = electromagnetic interference kam karta hai
  • Sabse bahari plastic cover = physical damage se protect
  • Radio frequency signal transmit karta hai
  • Types: Thicknet, Thinnet
  • Noise ke liye: Outer Conductor (bahi conductor) responsible hai — coaxial is noise-resistant
Optical Fiber Cable
  • Total Internal Reflection principle pe kaam karta hai
  • Glass ya plastic se bana hai
  • Core pe glass ki layer chadhana = Cladding
  • Sabse fast — highest bandwidth
  • Electromagnetic interference nahi — secure
  • FDDI mein use hota hai (200 km, >100 Mbps)
Wireless Media
  • Radio Waves = Sabhi directions mein jaati hain — Radio Link Transmission
  • Microwave = Line of sight — long distance
  • Infrared = Short range — IrDA port
  • Li-Fi = Light se data — visible spectrum use karta hai — Wi-Fi se fast — Wireless NAHI (wired optical)
  • Wi-Fi = Radio Waves | WiMAX = Spectrum
  • Optical Fiber = NOT wireless technology
