📶 OSI Model — 7 Layer Architecture (ISO, 1984)

OSI = Open System Interconnection — ISO द्वारा 1984 में design किया गया Reference/Framework Model (actual protocol नहीं)।
🧠 Mnemonic (Layer 7→1): "All People Seem To Need Data Processing"
Encapsulation = Sender: Layer 7→1 (हर layer header add करती है) | De-encapsulation = Receiver: Layer 1→7 (header remove होता है) | Data Structure = Stack (LIFO)
LayerनामPDUDeviceमुख्य Protocolsकाम (1-liner)
7 Application Message Gateway HTTP, HTTPS, FTP, SMTP, POP3, IMAP, DNS, Telnet, SNMP, DHCP User interface — end-user और Network के बीच direct interface
6 Presentation Message Gateway MPEG, MIDI, SSL, TLS, JPEG, GIF Encryption/Decryption, Compression, Translation (Data format)
5 Session Message Gateway NetBIOS, Socket, SYNCU Connection Establish/Terminate, Dialog Control (Synchronization)
4 Transport Segment (TCP) / Datagram (UDP) Gateway TCP, UDP Process-to-Process delivery, Segmentation, Flow & Error Control
3 Network Packet Router IP, ICMP, ARP, RARP, BGP, OSPF Logical Addressing, Routing, Packeting (IP Address)
2 Data Link Frame Switch, Bridge, NIC SLIP, PPP, HDLC, IEEE 802.3, Ethernet Error Detection/Correction, MAC Address, Framing
1 Physical Bits HUB, Repeater, Modem, NIC Ethernet, ATM, Frame Relay Electrical/Optical signals, Bit stream transmission, Cable/Wireless

🌐 TCP/IP Model — DOD Model (Department of Defense)

TCP/IP = 4-layer model (DOD Model) — OSI से पहले आया। Internet का actual working model।
ISO-OSI = Theoretical (Reference Model) | TCP/IP = Practical (Internet)
TCP/IP LayerOSI EquivalentProtocols
Application Layer Layer 7 + 6 + 5 (Application + Presentation + Session) HTTP, HTTPS, FTP, SMTP, POP3, IMAP, DNS, Telnet, SNMP, DHCP
Transport Layer Layer 4 (Transport) TCP, UDP
Internet Layer Layer 3 (Network) IP, ICMP, ARP, RARP, BGP, OSPF, NAT
Network Access Layer (Link Layer) Layer 2 + 1 (Data Link + Physical) Ethernet, Wi-Fi (IEEE 802.11), PPP, Frame Relay

HUB के प्रकार

  • Passive HUB = केवल wiring connector — कोई feature नहीं
  • Active HUB = Signal amplify करता है
  • Intelligent HUB = Management Software — N/W problems analyze

Modem (MOdulator-DEModulator)

  • Modulation = Digital → Analog (Telephone के लिए)
  • Demodulation = Analog → Digital (receive)
  • Modulation types: AM, FM, PM
  • Send करते समय: Digital → Analog पहले

NIC (Network Interface Card)

  • Alias: LAN Card, Ethernet Card, Network Adapter
  • MAC = 48 bits (6 bytes) — unique hardware address
  • पहले 3 bytes = OUI (Manufacturer ID)
  • Ethernet NIC (1980, Robert Metcalf) | Wireless NIC

Router के प्रकार

  • Wireless Router = WAP (Wi-Fi)
  • Core Router = Network के अंदर routing
  • Edge Router = Boundary पर — low capacity
  • Brouter = Bridge + Router combined

Optical Fiber — Key Facts

  • Principle: Total Internal Reflection
  • Glass या Plastic से बना
  • Core पर glass की layer = Cladding
  • सबसे तेज़, सबसे ज़्यादा Bandwidth
  • Electromagnetic interference नहीं = Secure
  • FDDI में use — 200 km, >100 Mbps
  • RJ45 connector = UTP cable (4 pairs = 8 wires)

Wireless Media

  • Radio Waves = सभी directions में — WiFi, Bluetooth
  • Microwave = Line of sight — Long distance
  • Infrared = Short range — IrDA port, Remote control
  • Li-Fi = Visible light spectrum — WiFi से तेज़
    Li-Fi = Optical (wired concept), wireless नहीं
  • WiFi = Radio Waves | WiMAX = Spectrum (IEEE 802.16)
  • Optical Fiber = Wireless technology नहीं है
  • Coaxial noise resistant क्यों? = Outer conductor (shielding)
