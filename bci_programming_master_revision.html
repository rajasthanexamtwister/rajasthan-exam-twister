Tokens & Identifier Rules

  • Token = C का सबसे छोटा meaningful unit: Keyword, Identifier, Literal/Constant, Operator, Special Symbol, White Space
  • C में ठीक 32 Keywords होते हैं — सभी Lowercase; Keyword को Identifier नहीं बना सकते
  • Identifier Rules: शुरुआत Alphabet या Underscore(_) से (Number से नहीं); अधिकतम लंबाई 31 characters (C/C++); Space allowed नहीं
  • ⚠ TRAP $ चिह्न — Java में Valid Identifier character है, C/C++ में NAHI!
  • White Space Characters = Enter/Space/Tab, इन्हें "Pilcrow" भी कहते हैं

पॉइंटर्स (Pointers)

  • Pointer = वह Variable जो किसी दूसरे Variable का Address Store करता है (int, char, array, function किसी का भी)
  • Size Architecture पर निर्भर: 32-bit=4 Bytes, 64-bit=8 Bytes
  • & = Address-of Operator (&a = a का address) | * = Dereference/Indirection Operator (*p = address पर मौजूद value)
  • NULL Pointer: int* p = NULL; → 0 address point करता है
  • Formula: p=&q; n=*p; ⇔ n=q;
  • उपयोग: Dynamic Memory Allocation, Arrays (नाम स्वयं Pointer है), Call by Reference, Multiple Return Values
⚠ TRAP & = Pointer Initialization में; * = Pointer Declare करने में AND Dereference करने में — दोनों जगह अलग Meaning!

🔵 OOP Concepts (C++ / Java)

Conceptअर्थ
EncapsulationData + Methods को एक Unit(Class) में बांधना
Abstractionकेवल आवश्यक जानकारी दिखाना, Implementation छिपाना
Inheritanceएक Class दूसरी Class के गुण प्राप्त करती है (Code Reusability)
Polymorphismएक ही नाम, अलग-अलग व्यवहार/Implementation
  • Object = Class का Instance | Class = Objects बनाने की Blueprint
  • Global Variable, Friend Class, Repetition — ये OOP Pillars नहीं हैं (Trap Question में बार-बार आता है)
  • Default Constructor = बिना Argument वाला | Constructor का कोई Return Type नहीं होता, नाम Class के जैसा होता है
  • Abstract Class = जिसमें कम-से-कम एक Pure Virtual Function हो (virtual void f()=0;)
  • Operator Overloading = एक Operator को अलग Data Types के लिए अलग Meaning देना
  • Ambiguous Constructor: जब Compiler दो Overloaded Constructors में अंतर नहीं कर पाता
  • C++ में Private Inheritance से Base की Public Members भी Derived में Private बन जाती हैं

C++ विशेष बिंदु (हैंडलिखित नोट्स से)

  • Inline Function: यह Function Call होते ही Code से Replace हो जाता है (कॉपी होकर); Overhead नहीं होता, Program Fast चलता है; Class के अंदर हर Function Default रूप से Inline होने की क्षमता रखता है
  • Pointer vs Reference: दोनों Aliasing Technique; Pointer=Address Store करता है+Memory चाहिए; Reference=कोई Address/Memory नहीं चाहिए, Declaration के समय ही Initialize होना चाहिए (बाद में नहीं बदल सकते)
  • Namespace: Extra Scope Provide करता है Call के लिए; Access: A::hi(); New C++ में Default Namespace = std (using namespace std;)
  • Exception Handling: 3 भाग — try{}, throw statement, catch(){} method; एक try के साथ Multiple catch() हो सकते हैं; हमेशा एक ही catch match होता है
  • Formatted Output (C vs C++): C में printf("%#o",0101) प्रकार के Format flags; C++ में Manipulators (setbase(), hex, oct, setprecision()) — Header iomanip.h; endl = Manipulator (New Line + Flush), \n = साधारण Line Feed
  • float में ~7 digit Support, double में ~15 digits Support लेकिन Default print में केवल 6 digits दिखते हैं
